# Functional Requirements

This document tracks the functional requirements for the ERP project.

## 1. Core Gameplay
- [ ] Users shall be able to progress through levels corresponding to book chapters.
- [ ] Gameplay shall be an incremental clicker mechanic.
- [ ] Enemies and NPCs shall be dynamically generated based on the current chapter's content.

## 2. Narrative & Immersion
- [ ] The system shall play the corresponding Eleven Reader audio book segment in the background for each level.
- [ ] Narrative triggers shall expose the Elysium Rising story as users advance.

## 3. Social & Competitive
- [ ] The system shall maintain global and chapter-specific leaderboards (Cumulative scores, Time Attack).
- [ ] The system shall provide a chat interface (General and Chapter-specific).
- [ ] Users shall be able to unlock achievements synced with Google Play.

## 4. Authentication
- [ ] Users shall be able to sign in using Google SSO.
- [ ] User sessions shall be persistent across devices.

## 5. Administration
- [ ] Administrators shall be able to monitor user activity and leaderboard integrity.
- [ ] Administrators shall be able to adjust narrative trigger parameters.
