## 1. Backend Architecture

### 1.1 Module Structure

```
backend/
├── routes/
│   ├── shop.py              # Player-facing shop endpoints (catalog, purchase, equip, boosters)
│   └── admin_shop.py        # Admin CRUD for shop catalog + admin refund
├── models/
│   └── shop.py              # ShopItem, ShopBundle, ShopBundleItem, PlayerShopItem, PlayerActiveBooster
├── services/
│   ├── shop_service.py      # Shop purchase logic, equip/unequip, collection queries
│   └── boost_service.py     # get_effective_multipliers() — combines subscription + shop boosters
```

### 1.2 Key Design Decisions

#### Account-Wide Ownership, Character-Level Skin Equip
Shop items are owned at the **player** level (persist through character deletion). Cosmetic equip state is split:

| Cosmetic Type | Equip Storage | Reason |
|:---|:---|:---|
| **Skins** | `player_characters.equipped_skin_id` | Skins render on the character; class restriction requires character context |
| **Flair** | `players.equipped_flair_id` | Account-wide, class-independent |
| **Badges** | `players.equipped_badge_id` | Account-wide, class-independent |
| **Avatars** | `players.equipped_avatar_id` | Account-wide, class-independent |

When a player deletes their character, `equipped_skin_id` is lost with the character row, but the skin remains in `player_shop_items` and can be re-equipped on a new character (if class matches).

#### Separate `player_shop_items` Table
Shop cosmetics live in their own table, not in `player_inventory` (which is for gear/equipment with slot limits from 2.4.2). Shop items have no slot cap — players can own unlimited cosmetics.

#### No Cron — Fully Lazy Booster Evaluation
Booster elapsed time is tracked via a counter (`elapsed_seconds`) rather than wall-clock calculation. The counter is incremented:
1. On each **session complete** (`/api/game/story/session/{id}/complete`)
2. On periodic **booster pings** from the frontend while a session is active
3. On any **booster status check** (lazy evaluation)

This avoids needing to retroactively reconstruct session windows.

#### `boost_service.py` — Standalone Utility
The combined multiplier function lives in its own service to avoid circular imports between `shop_service.py` and `subscription_service.py`.

```python
# backend/services/shop_service.py

from services.payment_service import debit_shards

def purchase_item(player_id: int, item_id: int, session: Session) -> dict:
    """Purchase a single shop item (cosmetic or booster).

    Returns: { "item": ShopItem, "new_balance": int, "booster_status": dict|None }
    """
    item = session.get(ShopItem, item_id)
    if not item or not item.is_active:
        raise ShopError("Item not found", 404)

    # Availability window check
    now = datetime.now(timezone.utc)
    if item.available_from and now < item.available_from:
        raise ShopError("This item is not yet available", 400)
    if item.available_until and now > item.available_until:
        raise ShopError("This item is no longer available", 400)

    # Negative balance block (from 3.1 refunds/disputes)
    meta = _get_player_meta(player_id, session)
    if meta.shard_balance < 0:
        raise ShopError("Your shard balance is negative. Purchase more shards first.", 400)

    # Balance check
    if meta.shard_balance < item.price_shards:
        raise ShopError("Insufficient shard balance", 400)

    # Category-specific validation
    if item.category == "skin" and item.class_restriction:
        character = _get_active_character(player_id, session)
        if not character or character.class_id != item.class_restriction:
            raise ShopError(f"This skin requires the {item.class_name} class", 400)

    if item.category in ("skin", "flair", "badge", "avatar"):
        # Check already owned
        existing = session.exec(
            select(PlayerShopItem).where(
                PlayerShopItem.player_id == player_id,
                PlayerShopItem.shop_item_id == item_id,
                PlayerShopItem.status == "owned",
            )
        ).first()
        if existing:
            raise ShopError("You already own this item", 400)

    # Debit shards (uses existing payment_service)
    debit_shards(
        player_id=player_id,
        amount=item.price_shards,
        source_type="shop_purchase",
        source_id=item_id,
        description=f"Purchased {item.name}",
        session=session,
    )

    result = {"item": item, "new_balance": meta.shard_balance - item.price_shards}

    if item.category in ("skin", "flair", "badge", "avatar"):
        # Create ownership record
        ownership = PlayerShopItem(
            player_id=player_id,
            shop_item_id=item_id,
            status="owned",
            purchased_at=now,
        )
        session.add(ownership)
        result["booster_status"] = None

    elif item.category == "booster":
        # Activate or extend booster
        booster_status = _activate_booster(player_id, item, session)
        result["booster_status"] = booster_status

    session.flush()
    return result
```

### 2.2 Booster Activation

```python
def _activate_booster(player_id: int, item: ShopItem, session: Session) -> dict:
    """Activate a booster or extend an existing one.

    item.item_metadata JSON: { "boost_type": "xp"|"essence"|"drop_rate",
                               "magnitude": 1.25, "duration_seconds": 3600 }
    """
    boost_config = item.item_metadata if item.item_metadata else {}
    boost_type = boost_config["boost_type"]
    magnitude = boost_config["magnitude"]
    duration_seconds = boost_config["duration_seconds"]

    # Check for existing active booster of this type
    active = session.exec(
        select(PlayerActiveBooster).where(
            PlayerActiveBooster.player_id == player_id,
            PlayerActiveBooster.boost_type == boost_type,
            PlayerActiveBooster.status == "active",
        )
    ).first()

    if active:
        # Extend: add duration, take max magnitude
        remaining = duration_seconds - active.elapsed_seconds
        active.duration_seconds = remaining + duration_seconds  # old remaining + new full duration
        active.elapsed_seconds = 0  # Reset counter; total duration is now the combined remaining
        active.magnitude = max(active.magnitude, magnitude)
        active.updated_at = datetime.now(timezone.utc)
        session.add(active)
        return {
            "boost_type": boost_type,
            "magnitude": active.magnitude,
            "remaining_seconds": active.duration_seconds,
            "extended": True,
        }
    else:
        # New booster
        booster = PlayerActiveBooster(
            player_id=player_id,
            boost_type=boost_type,
            magnitude=magnitude,
            duration_seconds=duration_seconds,
            elapsed_seconds=0,
            shop_item_id=item.id,
            status="active",
            activated_at=datetime.now(timezone.utc),
        )
        session.add(booster)
        return {
            "boost_type": boost_type,
            "magnitude": magnitude,
            "remaining_seconds": duration_seconds,
            "extended": False,
        }
```

### 2.3 Booster Timer Increment

```python
def increment_booster_time(player_id: int, elapsed_seconds: int, session: Session) -> list[dict]:
    """Increment elapsed time on all active boosters for a player.

    Called by:
    - Session complete endpoint (story_mode.py /complete)
    - Booster ping endpoint (shop.py /booster-ping)
    - Idle training tick (game_training.py)

    Returns list of expired boosters (if any).
    """
    active_boosters = session.exec(
        select(PlayerActiveBooster).where(
            PlayerActiveBooster.player_id == player_id,
            PlayerActiveBooster.status == "active",
        )
    ).all()

    expired = []
    for booster in active_boosters:
        booster.elapsed_seconds += elapsed_seconds
        booster.updated_at = datetime.now(timezone.utc)

        if booster.elapsed_seconds >= booster.duration_seconds:
            booster.status = "expired"
            booster.expired_at = datetime.now(timezone.utc)
            expired.append({
                "boost_type": booster.boost_type,
                "magnitude": booster.magnitude,
            })

        session.add(booster)

    if expired:
        session.flush()

    return expired
```

### 2.4 Cosmetic Equip/Unequip

```python
def equip_cosmetic(player_id: int, item_id: int, session: Session) -> None:
    """Equip a cosmetic item. Validates ownership and class restriction."""
    ownership = session.exec(
        select(PlayerShopItem).where(
            PlayerShopItem.player_id == player_id,
            PlayerShopItem.shop_item_id == item_id,
            PlayerShopItem.status == "owned",
        )
    ).first()
    if not ownership:
        raise ShopError("You don't own this item", 400)

    item = session.get(ShopItem, item_id)
    character = _get_active_character(player_id, session)
    player = _get_player(player_id, session)

    if item.category == "skin":
        if not character:
            raise ShopError("No active character", 400)
        if item.class_restriction and character.class_id != item.class_restriction:
            raise ShopError(f"This skin requires the {item.class_name} class", 400)
        character.equipped_skin_id = item_id
        session.add(character)

    elif item.category == "flair":
        session.execute(
            text("UPDATE players SET equipped_flair_id = :iid WHERE id = :pid"),
            {"iid": item_id, "pid": player_id},
        )

    elif item.category == "badge":
        session.execute(
            text("UPDATE players SET equipped_badge_id = :iid WHERE id = :pid"),
            {"iid": item_id, "pid": player_id},
        )

    elif item.category == "avatar":
        session.execute(
            text("UPDATE players SET equipped_avatar_id = :iid WHERE id = :pid"),
            {"iid": item_id, "pid": player_id},
        )

    session.flush()


def unequip_cosmetic(player_id: int, slot: str, session: Session) -> None:
    """Unequip a cosmetic by slot name. Reverts to default appearance."""
    character = _get_active_character(player_id, session)

    if slot == "skin":
        if character:
            character.equipped_skin_id = None
            session.add(character)
    elif slot == "flair":
        session.execute(
            text("UPDATE players SET equipped_flair_id = NULL WHERE id = :pid"),
            {"pid": player_id},
        )
    elif slot == "badge":
        session.execute(
            text("UPDATE players SET equipped_badge_id = NULL WHERE id = :pid"),
            {"pid": player_id},
        )
    elif slot == "avatar":
        session.execute(
            text("UPDATE players SET equipped_avatar_id = NULL WHERE id = :pid"),
            {"pid": player_id},
        )
    else:
        raise ShopError(f"Unknown cosmetic slot: {slot}", 400)

    session.flush()
```

### 2.5 Purchase Bundle

```python
def purchase_bundle(player_id: int, bundle_id: int, session: Session) -> dict:
    """Purchase a bundle. One-time only. Delivers unowned contents."""
    bundle = session.get(ShopBundle, bundle_id)
    if not bundle or not bundle.is_active:
        raise ShopError("Bundle not found", 404)

    # One-time check
    existing = session.exec(
        select(PlayerShopItem).where(
            PlayerShopItem.player_id == player_id,
            PlayerShopItem.source_bundle_id == bundle_id,
        )
    ).first()
    if existing:
        raise ShopError("You already purchased this bundle", 400)

    # Balance check
    meta = _get_player_meta(player_id, session)
    if meta.shard_balance < bundle.price_shards:
        raise ShopError("Insufficient shard balance", 400)

    # Debit shards
    debit_shards(
        player_id=player_id,
        amount=bundle.price_shards,
        source_type="shop_purchase",
        source_id=bundle_id,
        description=f"Purchased bundle: {bundle.name}",
        session=session,
    )

    # Deliver contents
    bundle_items = session.exec(
        select(ShopBundleItem).where(ShopBundleItem.bundle_id == bundle_id)
    ).all()

    delivered = []
    for bi in bundle_items:
        item = session.get(ShopItem, bi.shop_item_id)
        if not item:
            continue

        # Check if player already owns this item
        already_owned = session.exec(
            select(PlayerShopItem).where(
                PlayerShopItem.player_id == player_id,
                PlayerShopItem.shop_item_id == bi.shop_item_id,
                PlayerShopItem.status == "owned",
            )
        ).first()

        if already_owned and item.category != "booster":
            continue  # Skip already-owned cosmetics

        if item.category in ("skin", "flair", "badge", "avatar"):
            ownership = PlayerShopItem(
                player_id=player_id,
                shop_item_id=bi.shop_item_id,
                status="owned",
                source_bundle_id=bundle_id,
                purchased_at=datetime.now(timezone.utc),
            )
            session.add(ownership)
            delivered.append(item.name)
        elif item.category == "booster":
            _activate_booster(player_id, item, session)
            delivered.append(f"{item.name} (activated)")

    # Mark bundle as purchased (ownership record for the bundle itself)
    bundle_ownership = PlayerShopItem(
        player_id=player_id,
        shop_item_id=None,  # No single item — it's a bundle
        source_bundle_id=bundle_id,
        status="owned",
        purchased_at=datetime.now(timezone.utc),
    )
    session.add(bundle_ownership)

    session.flush()
    return {
        "bundle": bundle,
        "delivered": delivered,
        "new_balance": meta.shard_balance - bundle.price_shards,
    }
```

## 3. Boost Service — `boost_service.py`

### 3.1 Combined Multiplier Resolution

```python
# backend/services/boost_service.py

from services.subscription_service import get_subscriber_multipliers
from models.shop import PlayerActiveBooster

def get_effective_multipliers(player_id: int, session: Session) -> dict:
    """Combine subscription boosts and shop booster multipliers.

    This replaces all direct calls to get_subscriber_multipliers() in game systems.
    Returns the multiplicative combination of both boost sources.
    """
    sub = get_subscriber_multipliers(player_id, session)

    # Load active shop boosters
    active_boosters = session.exec(
        select(PlayerActiveBooster).where(
            PlayerActiveBooster.player_id == player_id,
            PlayerActiveBooster.status == "active",
        )
    ).all()

    # Check for expired boosters (lazy evaluation)
    shop_multipliers = {"xp": 1.0, "essence": 1.0, "drop_rate": 1.0}
    booster_details = []
    now = datetime.now(timezone.utc)

    for booster in active_boosters:
        remaining = booster.duration_seconds - booster.elapsed_seconds
        if remaining <= 0:
            # Expire it
            booster.status = "expired"
            booster.expired_at = now
            session.add(booster)
            continue

        shop_multipliers[booster.boost_type] = booster.magnitude
        booster_details.append({
            "boost_type": booster.boost_type,
            "magnitude": booster.magnitude,
            "remaining_seconds": remaining,
            "duration_seconds": booster.duration_seconds,
        })

    # Multiplicative stacking: subscription × shop
    return {
        "xp": round(sub["xp"] * shop_multipliers["xp"], 4),
        "essence": round(sub["essence"] * shop_multipliers["essence"], 4),
        "drop_rate": round(sub["drop_rate"] * shop_multipliers["drop_rate"], 4),
        "training_speed": sub["training_speed"],  # No shop booster for training speed
        "is_ascendant": sub["is_ascendant"],
        "continuous_streak": sub["continuous_streak"],
        "cumulative_months": sub["cumulative_months"],
        "stipend_shards": sub["stipend_shards"],
        "active_boosters": booster_details,
        # Breakdown for UI display
        "sub_multipliers": {
            "xp": sub["xp"],
            "essence": sub["essence"],
            "drop_rate": sub["drop_rate"],
        },
        "shop_multipliers": shop_multipliers,
    }
```

### 5.2 Admin Refund Flow

```python
def admin_refund_item(player_id: int, item_id: int, reason: str, session: Session):
    """Remove shop item from player and credit shards back."""
    ownership = session.exec(
        select(PlayerShopItem).where(
            PlayerShopItem.player_id == player_id,
            PlayerShopItem.shop_item_id == item_id,
            PlayerShopItem.status == "owned",
        )
    ).first()
    if not ownership:
        raise ShopError("Player doesn't own this item", 404)

    item = session.get(ShopItem, item_id)

    # Unequip if currently equipped
    _force_unequip_if_equipped(player_id, item, session)

    # Mark as refunded
    ownership.status = "refunded"
    ownership.refunded_at = datetime.now(timezone.utc)
    session.add(ownership)

    # For boosters: if active, expire it (remaining time forfeited)
    if item.category == "booster":
        active_booster = session.exec(
            select(PlayerActiveBooster).where(
                PlayerActiveBooster.player_id == player_id,
                PlayerActiveBooster.shop_item_id == item_id,
                PlayerActiveBooster.status == "active",
            )
        ).first()
        if active_booster:
            active_booster.status = "expired"
            active_booster.expired_at = datetime.now(timezone.utc)
            session.add(active_booster)

    # Credit shards back
    from services.payment_service import credit_shards_direct
    credit_shards_direct(
        player_id=player_id,
        amount=item.price_shards,
        source_type="admin_refund",
        source_id=item_id,
        description=f"Admin refund: {item.name} — {reason}",
        session=session,
    )

    session.flush()
```

## 8. Error Handling

### 8.1 Purchase Errors

| Error | Code | Handling |
|:---|:---|:---|
| Insufficient balance | 400 | Frontend disables button, shows deficit |
| Already owned (cosmetic) | 400 | Frontend shows "Owned" badge instead of Buy |
| Already purchased (bundle) | 400 | Frontend shows "Purchased" badge |
| Class mismatch (skin) | 400 | Frontend shows class label, filters wrong-class skins |
| Item unavailable (window) | 400 | Frontend hides expired items on catalog refresh |
| Item not found | 404 | Frontend removes from display |
| Negative balance | 400 | Frontend shows negative balance banner, disables all purchases |
| Rate limited | 429 | Frontend shows "Please wait" |

### 8.2 Booster Ping Validation

| Scenario | Handling |
|:---|:---|
| No active session | 400 — "No active session, timer paused" (frontend stops pinging) |
| `elapsed_seconds` > `shop_booster_max_elapsed_per_ping` | Clamp to max (anti-cheat) |
| No active boosters | 200 — empty list (no-op, frontend can stop pinging) |

### 8.3 Concurrent Purchases

- Shard debit uses `SELECT ... FOR UPDATE` row-level locking on `player_meta_progression`.
- Two rapid clicks result in the first succeeding and the second failing with "Insufficient balance" or "Already owned."
