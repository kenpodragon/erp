## Migration 046: Artifact System

### Pre-Existing Tables (to be migrated/extended)

> **Note:** The database already contains `artifacts` (4 seeded rows) and `player_collections` tables from the Phase 2.1 framework. Migration 046 must:
> 1. Rename `artifacts` to `artifacts_legacy` (preserve data for reference).
> 2. Create the new `curated_artifacts` + `curated_artifact_tiers` tables.
> 3. Migrate the 4 existing artifact rows into `curated_artifacts` with appropriate tier data.
> 4. Rename `player_collections` to `player_collections_legacy`.
> 5. Create the new `player_artifacts` table and migrate existing collection records.
> 6. Drop legacy tables after verification (or keep as `_legacy` until 2.7.4 polish).

### New Tables

#### `curated_artifacts`
Master definitions for hand-designed lore artifacts.

| Column | Type | Constraints | Description |
|:---|:---|:---|:---|
| `id` | `SERIAL` | `PRIMARY KEY` | |
| `name` | `VARCHAR(100)` | `NOT NULL UNIQUE` | Display name (e.g., "Cracked Data Core") |
| `description` | `TEXT` | `NOT NULL` | Short flavor text |
| `lore_text` | `TEXT` | | Extended lore for inspection modal |
| `icon_sprite_key` | `VARCHAR(100)` | `NOT NULL` | Sprite key for rendering |
| `source_type` | `VARCHAR(20)` | `NOT NULL CHECK (source_type IN ('boss', 'chapter', 'rare_spawn'))` | Where this artifact drops |
| `source_id` | `INTEGER` | | FK to scenes/chapters/entities (app-level, not DB FK due to polymorphism) |
| `source_hint` | `VARCHAR(255)` | `NOT NULL` | Human-readable drop source (e.g., "Chapter 3 Boss - The Pallid Mask") |
| `base_drop_chance` | `NUMERIC(6,4)` | `NOT NULL DEFAULT 0.01` | Base drop probability (0.0001 to 1.0) |
| `synergy_set_id` | `INTEGER` | `DEFAULT NULL` | Reserved for future synergy set FK |
| `is_active` | `BOOLEAN` | `NOT NULL DEFAULT TRUE` | Admin can deactivate |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL DEFAULT NOW()` | |
| `updated_at` | `TIMESTAMPTZ` | `NOT NULL DEFAULT NOW()` | |

**Indexes:**
- `idx_curated_artifacts_source` ON `(source_type, source_id)`
- `idx_curated_artifacts_active` ON `(is_active)` WHERE `is_active = TRUE`

**Trigger:** `trg_curated_artifacts_updated_at` — auto-sets `updated_at` on UPDATE.

#### `player_artifacts`
Player-owned artifact instances (both curated and generated).

| Column | Type | Constraints | Description |
|:---|:---|:---|:---|
| `id` | `SERIAL` | `PRIMARY KEY` | |
| `player_id` | `INTEGER` | `NOT NULL FK players ON DELETE CASCADE` | |
| `character_id` | `INTEGER` | `NOT NULL FK player_characters ON DELETE CASCADE` | |
| `artifact_type` | `VARCHAR(20)` | `NOT NULL CHECK (artifact_type IN ('curated', 'generated'))` | |
| `curated_artifact_id` | `INTEGER` | `FK curated_artifacts ON DELETE SET NULL` | Non-null for curated type |
| `artifact_code` | `VARCHAR(60)` | | Generated: "PREFIX_TYPE_SUFFIX". Curated: NULL |
| `name` | `VARCHAR(150)` | `NOT NULL` | Display name |
| `rarity` | `VARCHAR(20)` | `NOT NULL CHECK (rarity IN ('common', 'uncommon', 'rare', 'epic', 'cosmic'))` | |
| `icon_sprite_key` | `VARCHAR(100)` | `NOT NULL DEFAULT 'artifact_default'` | |
| `stat_bonuses` | `JSONB` | `NOT NULL DEFAULT '{}'` | Computed stat bonuses at this rarity |
| `acquired_from` | `VARCHAR(100)` | | Source context: 'boss_drop', 'scene_complete', 'chapter_mastery', 'rare_spawn' |
| `is_new` | `BOOLEAN` | `NOT NULL DEFAULT TRUE` | Cleared when viewed in Relic Gallery |
| `acquired_at` | `TIMESTAMPTZ` | `NOT NULL DEFAULT NOW()` | |

**Unique Constraints:**
- `uq_player_curated_artifact` ON `(character_id, curated_artifact_id)` WHERE `curated_artifact_id IS NOT NULL` — one curated artifact per character (rarity upgrades update in place)
- `uq_player_generated_artifact` ON `(character_id, artifact_code)` WHERE `artifact_code IS NOT NULL` — no duplicate generated artifacts per character

**Indexes:**
- `idx_player_artifacts_player` ON `(player_id)`
- `idx_player_artifacts_character` ON `(character_id)`
- `idx_player_artifacts_curated` ON `(curated_artifact_id)` WHERE `curated_artifact_id IS NOT NULL`
- `idx_player_artifacts_new` ON `(player_id)` WHERE `is_new = TRUE`

### Column Additions (Existing Tables)

#### `story_beats`
- `hidden_lore_text TEXT DEFAULT NULL` — Extra lore text gated by Intelligence stat

- `shard_balance BIGINT NOT NULL DEFAULT 0` — Premium currency (Elysium Shards) balance
- `total_shards_earned BIGINT NOT NULL DEFAULT 0` — Lifetime shards earned (achievements, purchases, etc.)
- `active_training_sessions INTEGER NOT NULL DEFAULT 0` — Count of completed active idle training click sessions

### New Table (Migration 046)

#### `shard_transactions`
Audit trail for all shard balance changes (achievements, future purchases, refunds).

| Column | Type | Constraints | Description |
|:---|:---|:---|:---|
| `id` | `SERIAL` | `PRIMARY KEY` | |
| `player_id` | `INTEGER` | `NOT NULL FK players ON DELETE CASCADE` | |
| `amount` | `BIGINT` | `NOT NULL` | Positive = credit, negative = debit |
| `balance_after` | `BIGINT` | `NOT NULL` | Balance after this transaction |
| `source_type` | `VARCHAR(30)` | `NOT NULL CHECK (source_type IN ('achievement', 'purchase', 'refund', 'admin_grant', 'admin_deduct', 'spend'))` | |
| `source_id` | `INTEGER` | | FK to achievements, or Stripe payment ID, etc. (app-level) |
| `description` | `VARCHAR(255)` | | Human-readable note |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL DEFAULT NOW()` | |

**Indexes:**
- `idx_shard_transactions_player` ON `(player_id)`
- `idx_shard_transactions_source` ON `(source_type)`

> **Note:** This table provides the transactional audit trail needed for 3.0 (Stripe integration). In 2.7, only `achievement` source_type is used. Future source types (`purchase`, `refund`, `spend`) are added by 3.0.

## Migration 047: Achievement & Title System

### New Tables

#### `titles`
Earnable display titles for players.

| Column | Type | Constraints | Description |
|:---|:---|:---|:---|
| `id` | `SERIAL` | `PRIMARY KEY` | |
| `name` | `VARCHAR(100)` | `NOT NULL UNIQUE` | e.g., "the Awakened" |
| `display_format` | `VARCHAR(10)` | `NOT NULL CHECK (display_format IN ('prefix', 'suffix'))` | Where the title appears relative to name |
| `achievement_id` | `INTEGER` | `FK achievements ON DELETE SET NULL` | Which achievement grants this title (added via ALTER TABLE after achievements is created) |
| `sort_order` | `INTEGER` | `NOT NULL DEFAULT 0` | |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL DEFAULT NOW()` | |

> **Migration Note:** `titles` is created first (without `achievement_id` FK), then `achievements` is created (with `reward_title_id FK titles`), then `ALTER TABLE titles ADD COLUMN achievement_id INTEGER REFERENCES achievements(id) ON DELETE SET NULL` is run to avoid circular dependency.

## Entity Relationship Notes

```
curated_artifacts ─┬── curated_artifact_tiers (1:5, one per rarity)
                   └── player_artifacts (1:many via curated_artifact_id)

artifact_type_bases ─┐
artifact_prefixes  ──┼── player_artifacts (generated artifacts reference these by code)
artifact_suffixes  ──┘

achievements ──── player_achievements (1:many)
             └── titles (via reward_title_id)

titles ──── player_titles (1:many)
       └── player_characters.equipped_title_id

leaderboard_cache ──── players (via player_id)
```
