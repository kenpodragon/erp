# DB Schema for REC 2.5: Audio & Music Integration

This document defines the database updates required to support the atmospheric audio system, procedural chiptune generation, and event-driven SFX.

---

## 1. New Tables

### 1.1 `atmospheres`
Defines a set of themed music tracks for different game states, supporting **Synchronized Stems** for dynamic layering.
```sql
CREATE TABLE IF NOT EXISTS atmospheres (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) UNIQUE NOT NULL, -- e.g., "Deep Tower", "Neon Slums"
    description TEXT,
    
    -- Music Stems (JSONB: { "state": ["path1", "path2", ...] })
    -- States: explore, combat, boss, mystery
    -- Each array contains paths to synchronized files for layering.
    stems_json JSONB DEFAULT '{
        "explore": [],
        "combat": [],
        "boss": [],
        "mystery": []
    }',
    
    -- Procedural generation parameters (for re-generation)
    generator_bpm INTEGER DEFAULT 120,
    generator_key VARCHAR(10) DEFAULT 'C',
    generator_scale VARCHAR(50) DEFAULT 'major',
    generator_complexity INTEGER DEFAULT 5,
    generator_seed INTEGER,
    
    created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);
```

### 1.2 `audio_configs`
Global mappings for system-wide SFX and default music. Individual components trigger these via the `useAudio` hook.
```sql
CREATE TABLE IF NOT EXISTS audio_configs (
    id SERIAL PRIMARY KEY,
    config_key VARCHAR(100) UNIQUE NOT NULL, -- e.g., 'ui_click', 'level_up', 'boss_defeat_fanfare'
    audio_path VARCHAR(255), -- relative path to frontend/public/audio/sfx/
    base_volume FLOAT DEFAULT 1.0,
    pitch_variation FLOAT DEFAULT 0.0, -- Max random pitch shift for variety
    spatial_enabled BOOLEAN DEFAULT FALSE, -- Whether to enable stereo panning based on X-coord
    created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);
```

## 2. Table Updates (Inheritance Hierarchy)

### 2.1 `books`, `chapters`, `scene_gameplay_data`
```sql
ALTER TABLE books ADD COLUMN IF NOT EXISTS atmosphere_id INTEGER REFERENCES atmospheres(id);
ALTER TABLE chapters ADD COLUMN IF NOT EXISTS atmosphere_id INTEGER REFERENCES atmospheres(id);
ALTER TABLE scene_gameplay_data ADD COLUMN IF NOT EXISTS atmosphere_id INTEGER REFERENCES atmospheres(id);
```

### 2.2 `entity_gameplay_data`
For unique boss themes and entity-specific SFX.
```sql
ALTER TABLE entity_gameplay_data ADD COLUMN IF NOT EXISTS unique_boss_theme_id INTEGER REFERENCES atmospheres(id);
ALTER TABLE entity_gameplay_data ADD COLUMN IF NOT EXISTS death_sfx_key VARCHAR(100); -- Refers to audio_configs.config_key
```

### 2.3 `skills`
Mapping skill activations to specific sound effects.
```sql
ALTER TABLE skills ADD COLUMN IF NOT EXISTS activate_sfx_key VARCHAR(100); -- Refers to audio_configs.config_key
```

## 3. Implementation Notes

- **Synchronized Stem Layering (Option A):** The `AudioPlayer` must initialize multiple audio elements for the active state (e.g., `explore`) and start them simultaneously. Volume of non-base stems is modulated by the game's `intensity` level.
- **Backend BPM Generation:** Different BPM variants for the same atmosphere are stored as separate `atmosphere` rows or handled by the generator producing unique stem sets for specific chapters.
- **Component-Level SFX:** Individual components (e.g., `EntitySprite`, `SkillButton`) use a `useAudio` hook to trigger sounds. This hook handles the lookup from `audio_configs` and applies spatial panning based on the component's relative X-coordinate in the viewport.
- **Inheritance Resolution Order:** 
  1. `entity_gameplay_data.unique_boss_theme_id` (if boss battle)
  2. `scene_gameplay_data.atmosphere_id` (if present)
  3. `chapters.atmosphere_id`
  4. `books.atmosphere_id`
  5. `audio_configs.config_key = 'default_music'`
- **MP3 Conversion:** All generated `.wav` files must be compressed to `.mp3` for production, but the `audio_path` in DB should refer to the finalized asset in `frontend/public/music`.
