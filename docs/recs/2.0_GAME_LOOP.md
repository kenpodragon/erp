# ERP: Game Loop & Interface Requirements

This document defines the detailed game loop mechanics, UI layout, and interface requirements for the Elysium Rising mmorPg. It serves as the primary reference for building the gameplay portion of the application.

---

## 1. High-Level Game Loop Overview

The game has **three interconnected loops** that feed into each other:

```
┌─────────────────────────────────────────────────────────┐
│                   OVERWORLD (Hub)                        │
│   Your Chronicle-style node map + Magic Research 2 UI   │
│                                                         │
│   ┌─────────────┐         ┌──────────────────┐          │
│   │  STORY MODE │◄───────►│  IDLE TRAINING   │          │
│   │  (Clicker)  │ rewards │  (Melvor Idle)   │          │
│   └─────────────┘         └──────────────────┘          │
│         │                         │                      │
│         │  gold + resources       │  base stats + skills │
│         └────────┬────────────────┘                      │
│                  ▼                                        │
│         ┌──────────────┐                                 │
│         │  PROGRESSION │                                 │
│         │  & UNLOCKS   │                                 │
│         └──────────────┘                                 │
└─────────────────────────────────────────────────────────┘
```

### Loop A: Overworld / Hub (Your Chronicle + Magic Research 2)
- The main screen players see after login and character selection.
- Node-based chapter/scene map showing progression through the Towers of Elysium story.
- Entry point to Story Mode (clicking game) and Idle Training (skill progression).

### Loop B: Story Mode / Clicker Combat (Clicker Heroes)
- Active gameplay where players click to deal damage, defeat waves of enemies, and fight bosses.
- Gated by audiobook narration - players cannot advance faster than 1x playback speed.
- Rewards gold and resources used in Idle Training.

### Loop C: Idle Training (Melvor Idle)
- Passive/idle skill training that runs in the background or on a dedicated tab.
- Skills trained here provide base stats and unlock abilities for Story Mode.
- Only one skill can train at a time.

### 3.2 Story/Narrative Area
- [x] **Audiobook Playback:** *(Eleven Reader deferred — replaced with WPM-timed text display + Web Audio synthesis music)*
- [x] **Text Display:** Story text displayed paragraph-by-paragraph via NarrativeBlock. *(PNG copy-protection deferred; hook documented in C_STORY_ASSET_GENERATORS.md)*
- [x] **Text Pacing:** Text appears paragraph by paragraph, timed with WPM-based delay. Players can scroll back to re-read completed portions.
- [x] **Progression Gate:** Players cannot advance until narrative reaches 100% AND waves complete (dual-condition gate).
- [x] **Replay Behavior:** On replays of previously completed scenes, players can skip ahead freely.

### 3.3 Combat Area
Inspired by Clicker Heroes' enemy-centric combat display.

- [x] **Enemy Display:** Large, centered enemy sprite with idle/damage/death animations. *(PixiJS v8 — generic shadow sprites with zone-scaled stats)*
- [x] **Enemy HP Bar:** Prominent health bar with numerical HP display. Color shifts from green to yellow to red.
- [x] **Click-to-Attack:** Clicking anywhere in the combat area deals damage. Each click shows a floating damage number.
- [x] **Wave Counter:** Shows current wave out of total waves for this scene (e.g., "Wave 3/10").
- [x] **Zone Level:** Displays the current difficulty level within the scene.
- [x] ~~**Enemy Info:**~~ *(Removed — enemy name + HP displayed inline below sprite; hover tooltip not needed)*
- [x] **Critical Hits:** Visual flair (screen shake, larger numbers, color change) for critical damage. *(CombatStage.tsx: shake triggers at HP < 10%; BossStage.tsx: 50ms decay)*
- [x] **Enemy Defeat:** Death animation + gold drop animation. Next enemy spawns after brief delay.

### 3.4 Wave & Boss System
- [x] **Standard Waves:** Each scene has a set number of enemy waves. Enemies get progressively harder within a scene.
- [ ] **Wave Composition:** Later waves may contain multiple enemies displayed simultaneously (damage splits or AoE mechanics). *(Not yet implemented — single enemy per wave)*
- [x] **Mini-Boss (Scene Boss):** Appears at the end of each scene's waves. Has unique mechanics:
  - Higher HP pool with visible phase transitions.
  - Timer-based enrage (if not killed fast enough, damage increases).
  - Lore-accurate abilities from the book (e.g., specific magic attacks).
- [x] **Chapter Boss (Major Boss):** Appears at the final scene of each chapter. Unique mechanics beyond clicking:
  - **Target Zones:** Click specific highlighted areas on the boss sprite to deal damage. *(BossStage.tsx — 3 interrupt types)*
  - **Skill Checks:** Require minimum Idle Training skill levels (e.g., "Magic Defense Lv5 required to survive this attack"). *(Deferred — skill check gating not implemented)*
  - **Phase Mechanics:** Multi-phase fights with changing attack patterns. *(Interrupt zones serve as phases)*
  - **Cutscene Transitions:** Between phases, short narrative cutscenes play. *(NarrativeReveal.tsx post-boss)*
- [x] **Boss Defeat Cutscene:** On final boss defeat, a cinematic plays featuring text from the book's chapter ending with accompanying visuals. *(NarrativeReveal.tsx — staged cinematic overlay with lore text from DB)*

### 3.5 Hero Panel (Bottom Left)
- [x] **Character Portrait:** Small avatar with level indicator. *(HeroStats.tsx — class icon + level display)*
- [x] **Stats Display:** Current click damage, DPS (damage per second from auto-attacks + clicking), critical chance.
- [x] **Level Progress:** XP bar showing progress to next level within this story session. *(HeroStats.tsx — session level + XP bar)*
- [x] **Status Effects:** Active buff/debuff icons with duration timers.

### 3.6 Skill Hotbar (Bottom Center)
- [x] **Skill Slots:** 9 skill slots mapped to keyboard keys [1]-[9] or clickable buttons. *(SkillsHotbar.tsx — dual hotbar rows)*
- [x] **Skill Source:** Skills are unlocked based on Idle Training progress. Higher Idle Training levels unlock more powerful skill tiers.
- [x] **Skill Purchase:** Skills must be purchased with in-session gold before they can be used (like Clicker Heroes hero abilities).
- [x] **Cooldowns:** Visual cooldown overlay on each skill button.
- [x] **Skill Types:**
  - **Damage Skills:** Burst damage, AoE, damage-over-time. *(Super Clicks, Powersurge)*
  - **Buff Skills:** Temporary click damage boost, critical chance increase, auto-click speed boost. *(Lucky Strikes, Clickstorm)*
  - **Utility Skills:** Gold multiplier, enemy slow, healing. *(Metal Detector, Golden Clicks)*

### 3.7 Gold & Upgrade Panel (Bottom Right)
- [x] **Gold Counter:** Running total of gold earned this session. Animated increment on enemy kills. *(GoldOdometer.tsx)*
- [x] **Upgrade Menu:** Expandable panel showing purchasable upgrades: *(UpgradeMenu.tsx — x1/x10/x100/MAX)*
  - Click Damage +X (scaling cost).
  - Auto-Click Speed (clicks per second while idle).
  - Critical Chance % increase.
  - Skill-specific upgrades.
- [x] **Upgrade Scaling:** Each purchase increases cost exponentially (standard incremental scaling). *(1.07^(L-1) formula)*

### 3.8 Session Reset Mechanic
- [x] **Fresh Start Per Entry:** Every time a player enters Story Mode for a scene, they start at:
  - Level 0 within the session.
  - 0 gold, no skills purchased.
  - Base click damage derived from Idle Training stats (higher Idle Training = higher floor).
- [x] **Internal Progression:** Within a session, players earn gold, buy upgrades, and level up - all temporary to that session.
- [x] **Death Mechanic:** If HP reaches 0 (from boss attacks or timed events):
  - Player respawns at the last completed wave checkpoint. *(Reset to wave 9 or last boss checkpoint)*
  - Gold and purchased upgrades are retained.
  - Can continue attempting from the checkpoint.
- [x] **Exit Rewards:** When the player exits Story Mode (voluntarily or after boss defeat), rewards are calculated:
  - Resources based on: highest wave reached, total gold earned, enemies defeated, boss kills. *(PostBattleSummary.tsx)*
  - Resources are converted to Idle Training currency at a level-balanced rate.

## 6. Economy Flow

```
Story Mode (Clicker)                    Idle Training (Skills)
    │                                        │
    │ earn Gold (in-session only)             │ consumes Elysium Essence
    │ earn Resources (on exit)               │ provides base stats
    │                                        │ unlocks Story Mode skills
    ▼                                        ▼
┌──────────────────────────────────────────────────┐
│                   OVERWORLD                       │
│                                                   │
│  Resources ──► Buy Training Materials ──► Skills  │
│  Gold (session) ──► In-session upgrades only      │
│  Premium Shards ──► Cosmetics, QoL boosters       │
│                                                   │
└──────────────────────────────────────────────────┘
```

### 6.1 Currency Types
- [x] **Gold:** Earned in Story Mode. Spent only within that session on upgrades. Does not persist between sessions.
- [x] **Elysium Essence:** Earned as a reward when exiting Story Mode. Spent in Idle Training to fuel skill progression.
- [ ] **Training Materials:** Purchased with Elysium Essence in the Shop. Required to begin training specific skills.
- [ ] **Elysium Shards (Premium):** Purchased with real money via Stripe. Used for cosmetics, auto-train tokens, and quality-of-life items. Never pay-to-win.

### 6.2 Reward Calculation (Story Mode Exit)
- [x] Base reward = f(chapter_level, highest_wave, enemies_defeated)
- [x] Bonus multipliers for: boss kills, no-death runs, speed completion.
- [x] Diminishing returns on repeated plays of the same scene (encourages forward progression).
- [x] First-time completion bonus (significant one-time reward).

## 8. Anti-Cheat & Validation

- [x] **Click Rate Limiting:** Server validates click rate. 20 CPS cap (configurable via game_configs). Backend validates batch pings.
- [x] **Server-Side Damage Calculation:** Client sends click events; server calculates actual damage based on verified stats. Client displays optimistically but server is authoritative.
- [x] **Audiobook Gate Enforcement:** Narrative duration tracked server-side. Client cannot self-report completion.
- [x] **Session Integrity:** Session gold, upgrades, and progress are validated server-side on exit. Anomalous values are rejected.
- [x] **Offline Training Cap:** Server calculates offline gains on login based on last-seen timestamp. Cannot exceed realistic caps.

## 99. Deferred Features

These features are out of scope for the current implementation. Documented here for future phases.

### 99.1 Endgame Zone (Post-Boss) — *from §5.2*
- [ ] **Continued Play:** Players can remain in the chapter's Story Mode after beating the boss.
- [ ] **Background Music Only:** Narration stops; background music continues.
- [ ] **Infinite Scaling:** Enemies continue spawning with progressively increasing difficulty (more per wave, higher HP/damage, occasional mini-bosses).
- [ ] **Reward Scaling:** Continued play earns gold/resources at diminishing returns.
- [ ] **Leaderboard Integration:** Highest wave reached tracked on chapter-specific leaderboards.

### 99.2 New Game+ (Future Loops) — *from §5.3*
- [ ] **Reset Progression:** On subsequent playthroughs: stronger enemies, palette changes, more enemies per wave, exclusive NG+ drops.
- [ ] **Skip Narration:** Previously completed chapters allow free progression without narrative gate.
- [ ] **Prestige System:** NG+ completions grant permanent prestige bonuses (small % stat increases).
