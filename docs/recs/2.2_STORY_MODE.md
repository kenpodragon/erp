# REC 2.2: Loop B - Story Mode / Clicker Combat (Active Play)

This document defines the checklist of requirements for the active gameplay loop, where players progress through the narrative via audiobook-gated combat.

---

## 1. Combat Engine (Clicker Heroes Style)
- [ ] **1.1 Core Engine (PixiJS)**
    - [ ] Implement high-performance sprite rendering for player and enemies.
    - [ ] Create animated HP bars with color-shifting health states (Green -> Yellow -> Red).
    - [ ] Implement floating damage numbers with visual variance (size/color) for critical hits.
    - [ ] **Critical Hits:** 2x base damage multiplier (Configurable via `game_configs`).
    - [ ] Develop damage-on-click logic based on character stats and session upgrades.
    - [ ] **Click Rate Limiting:** 
        - [ ] Frontend: Cap at 20 CPS (Configurable via `game_configs`).
        - [ ] Backend: Validate batch pings (every 2s) to ensure `clicks / time <= cap`.
    - [ ] Implement Auto-DPS logic derived from Idle Training skill levels.
    - [ ] Add screen shake and visual feedback for heavy hits/crits.

- [ ] **1.2 Wave & Progression System**
    - [ ] **Wave Balancing:** 
        - [ ] Calculate required waves: 1 wave per 30 seconds of audio duration (Configurable via `game_configs`).
    - [ ] **HP Scaling Logic:** 
        - [ ] Use formula: $Health = 10 \times (1.55^{Zone-1} + Zone - 1)$ for zones 1-140.
        - [ ] Scale factor (1.55) must be a configurable setting in the DB.
    - [ ] Implement "10 monsters per zone" logic (9 minions, 1 boss every 5/10 zones).
    - [ ] Create a **Progression Mode** toggle (automatic advancement to the next zone).
    - [ ] Create a **Farm Mode** toggle (loops current zone for gold grinding).
    - [ ] Implement **Primal Boss** logic (25% spawn chance for extra rewards).
    - [ ] Implement **Mini-Boss (Scene Boss)** mechanics:
        - [ ] 30-second enrage timer.
        - [ ] Phase transitions based on HP thresholds.
    - [ ] Implement **Chapter Boss** mechanics:
        - [ ] **Interrupt Zones (Option C):** Targeted zones appear during boss "charge-up" phases; clicking N times interrupts and prevents massive damage.
        - [ ] Skill-based checks (e.g., minimum Magic Defense required to survive).
    - [ ] Implement failure/death logic: Reset to Wave 9 or last boss checkpoint.

- [ ] **1.3 Active Skill System**
    - [ ] **Cooldown Logic:** 
        - [ ] Support for **Global Cooldown (GCD)** and **Individual Cooldowns**, configured per skill in the `skills` table.
    - [ ] Implement 30s active duration and cooldown tracking for all skills.
    - [ ] **Skill Scaling Logic:** 
        - [ ] Baseline power derived from **Idle Training Level** (e.g., Lv 500 base).
        - [ ] In-session: Skill is locked initially; must be **purchased with Session Gold** to activate.
        - [ ] In-session: Skill can be leveled further with gold during the run (Level 1, 2, etc. multipliers).
    - [ ] **Clickstorm:** Auto-click at 10 CPS.
    - [ ] **Powersurge:** +100% DPS multiplier.
    - [ ] **Lucky Strikes:** +50% Crit Chance.
    - [ ] **Metal Detector:** +100% Gold drop multiplier.
    - [ ] **Golden Clicks:** Earn % of monster gold per click.
    - [ ] **The Dark Ritual:** 
        - [ ] Apply +1.05x DPS multiplier.
        - [ ] **Persistence:** Multiplier persists across all scenes in the current **Chapter**; resets upon starting a new Chapter.
    - [ ] **Super Clicks:** +200% Click Damage.
    - [ ] **Energize:** Double effect of the next skill used.
    - [ ] **Reload:** Reduce cooldown of the last skill used.

## 2. Narrative Experience & Eleven Reader

- [ ] **2.1 Audio Integration**
    - [ ] Real-time streaming of chapter/scene audio via Eleven Reader.
    - [ ] **Pause Sync:** Pausing the game (menu/manual) automatically pauses audio narration.
    - [ ] Implement play/pause and volume controls.
    - [ ] Server-side tracking of audio progress to enforce the narrative gate.

- [ ] **2.2 Synced Text Overlay**
    - [ ] Display story text paragraph-by-paragraph, synced with audio playback.
    - [ ] **Sync Mapping:** Retrieve timestamp-to-asset mapping from the DB (`scene_audio_sync` table).
    - [ ] **Pre-rendered Assets:** Render text as copy-protected PNG images.
    - [ ] Implement "Scroll Back" functionality for completed segments.

- [ ] **2.3 Narrative Gating & Completion**
    - [ ] **Dual-Condition Completion:** 
        - [ ] **Condition A:** Audio segment must reach 100% completion.
        - [ ] **Condition B:** Required waves/bosses for the scene must be defeated.
    - [ ] **Extended Combat:** If waves finish before audio, generate extra waves until audio completes.
    - [ ] **Post-Completion Choice:** Upon finishing both, allow user to **CONTINUE** (stay and farm) or **GO BACK TO OVERWORLD**.
    - [ ] Lock "Next Scene" node until current segment is 100% complete (Audio + Waves).
    - [ ] Allow "Skip Gate" functionality for previously completed (100%) nodes.

- [ ] **2.4 Cinematics**
    - [ ] Chapter-end cutscene system for post-boss victory.
    - [ ] High-fidelity text overlays and atmospheric visual shifts matching book climax.

## 6. Database Schema (Technical Reference)

The following schema supports Story Mode session persistence, dynamic configuration, and meta-progression. (Reference: `db/013_story_mode_state.sql`, `db/014_skill_and_config_refinement.sql`)

### 6.1 Global Configuration
Stores admin-tunable settings (e.g., click caps, HP scaling, wave duration).
- `game_configs (key, value_json, description)`

### 6.2 Session Tracking
Tracks active progress in a story scene.
- `player_story_sessions`
    - `id`, `player_id`, `scene_id`, `chapter_id`
    - `current_zone`, `current_wave`
    - `session_gold`
    - `dark_ritual_multiplier` (Chapter-persistent)
    - `audio_progress_pct`, `audio_finished`, `required_waves_finished`
    - `is_active`

### 6.3 Narrative Sync
Maps audio timestamps to PNG text assets.
- `scene_audio_sync (scene_id, timestamp_seconds, asset_key, paragraph_index)`

### 6.4 In-Session Upgrades
Temporary upgrades purchased with session gold.
- `session_upgrades (session_id, upgrade_type, target_id, level, total_cost_paid, current_multiplier)`

### 6.5 Meta-Progression
Permanent currency earned from Story Mode.
- `player_meta_progression (player_id, elysium_essence, total_essence_earned, spent_essence)`
