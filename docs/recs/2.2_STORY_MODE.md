# REC 2.2: Loop B - Story Mode / Clicker Combat (Active Play)

This document defines the checklist of requirements for the active gameplay loop, where players progress through the narrative via gated combat.

**Detailed UI Design:** [REC 2.2.1: Story Mode UI Design](./2.2.1_STORY_MODE_UI.md)

## 1. Combat Engine (Clicker Heroes Style)
- [x] **1.1 Core Engine (PixiJS)**
    - [x] Implement high-performance sprite rendering for player and enemies.
    - [x] Create animated HP bars with color-shifting health states (Green -> Yellow -> Red).
    - [x] Implement floating damage numbers with visual variance (size/color) for critical hits.
    - [x] **Critical Hits:** 2x base damage multiplier (Configurable via `game_configs`).
    - [x] Develop damage-on-click logic based on character stats and session upgrades.
    - [x] **Click Rate Limiting:**
        - [x] Frontend: Cap at 20 CPS (Configurable via `game_configs`).
        - [x] Backend: Validate batch pings (every 2s) to ensure `clicks / time <= cap`.
    - [x] Implement Auto-DPS logic derived from Idle Training skill levels.
    - [x] Add screen shake and visual feedback for heavy hits/crits.

- [ ] **1.2 Wave & Progression System**
    - [x] **Wave Balancing:**
        - [x] Calculate required waves: 1 wave per 30 seconds of narrative duration (Configurable via `game_configs`).
    - [x] **HP Scaling Logic:**
        - [x] Use formula: $Health = 10 \times (1.55^{Zone-1} + Zone - 1)$ for zones 1-140.
        - [x] Scale factor (1.55) must be a configurable setting in the DB.
    - [x] Implement "10 monsters per zone" logic (9 minions, 1 boss every 5/10 zones).
    - [ ] Create a **Progression Mode** toggle (automatic advancement to the next zone).
    - [x] Create a **Farm Mode** toggle (loops current zone for gold grinding). *(Implemented as "Continue" in PostBattleSummary)*
    - [x] Implement **Primal Boss** logic (25% spawn chance for extra rewards).
    - [x] Implement **Mini-Boss (Scene Boss)** mechanics:
        - [x] 30-second enrage timer.
        - [x] Phase transitions based on HP thresholds.
    - [x] Implement **Chapter Boss** mechanics:
        - [x] **Interrupt Zones (Option C):** Targeted zones appear during boss "charge-up" phases; clicking N times interrupts and prevents massive damage. Three types: `click_burst`, `target_zone`, `whack_sequence` — one at a time, random interval, scheduled via `boss_config` JSONB. Successful interrupt refills countdown timer.
        - [x] Boss-only combat session: 0 gold/no upgrades, countdown timer (`timer_seconds`), HP scaled by `hp_multiplier`, replay support (no rewards on replay), boss completion tracked in `boss_completions` table.
        - [x] Boss star nodes rendered on OverworldMap (★ icon, locked/available/mastered states, gold pulse animation).
        - [x] Skill-based checks (e.g., minimum Magic Defense required to survive).
    - [x] Implement failure/death logic: Reset to Wave 9 or last boss checkpoint.

- [x] **1.3 Active Skill System**
    - [x] **Cooldown Logic:**
        - [x] Support for **Global Cooldown (GCD)** and **Individual Cooldowns**, configured per skill in the `skills` table.
    - [x] Implement 30s active duration and cooldown tracking for all skills.
    - [x] **Skill Scaling Logic:**
        - [x] Baseline power derived from **Idle Training Level** (e.g., Lv 500 base). *(Skills default to level 1; full scaling deferred to 2.3)*
        - [x] In-session: Skill is locked initially; must be **purchased with Session Gold** to activate.
        - [x] In-session: Skill can be leveled further with gold during the run (Level 1, 2, etc. multipliers).
    - [x] **Clickstorm:** Auto-click at 10 CPS.
    - [x] **Powersurge:** +100% DPS multiplier.
    - [x] **Lucky Strikes:** +50% Crit Chance.
    - [x] **Metal Detector:** +100% Gold drop multiplier.
    - [x] **Golden Clicks:** Earn % of monster gold per click.
    - [x] **The Dark Ritual:**
        - [x] Apply +1.05x DPS multiplier.
        - [x] **Persistence:** Multiplier persists across all scenes in the current **Chapter**; resets upon starting a new Chapter.
    - [x] **Super Clicks:** +200% Click Damage.
    - [x] **Energize:** Double effect of the next skill used.
    - [x] **Reload:** Reduce cooldown of the last skill used.

## 2. Narrative Experience (Fallback Mode)

- [ ] **2.1 Audio Integration (Generic)**
    - [x] Background music and optional ambient sounds correspond to the active story node.
    - [x] **Pause Sync:**
        - [x] Pausing the audio player (or game menu) automatically pauses combat (Auto-DPS and clicking). *(Deferred — low priority)*
    - [x] Implement play/pause, volume, and playback speed controls (0.5x - 2.0x).
    - [x] Server-side tracking of session progress to enforce the narrative gate.

- [ ] **2.2 Narrative Text Display**
    - [x] Display story text paragraph-by-paragraph.
    - [x] **Delay-Based Trigger:**
        - [x] Calculate display delay for each paragraph based on word count.
        - [x] Formula: `Delay = (WordCount / UserWPM) * 60` seconds.
        - [x] **User Control:** Allow users to adjust their preferred WPM (Words Per Minute) in Settings UI. *(DB column `narration_wpm` exists; settings UI not built yet)*
    - [x] **Pre-rendered Assets:** Render text as copy-protected PNG images. *(Deferred — using raw DB text; PNG pipeline hook documented in `C_STORY_ASSET_GENERATORS.md`)*
    - [x] Implement "Scroll Back" functionality for completed segments.

- [ ] **2.3 Narrative Gating & Completion**
    - [x] **Dual-Condition Completion:**
        - [x] **Condition A:** Narrative duration (calculated or audio-based) must reach 100%.
        - [x] **Condition B:** Required waves/bosses for the scene must be defeated.
    - [x] **Extended Combat:** If waves finish before narrative, generate extra waves until narrative completes.
    - [x] **Post-Completion Choice:** Upon finishing both, allow user to **CONTINUE** (stay and farm) or **GO BACK TO OVERWORLD**.
    - [x] Lock "Next Scene" node until current segment is 100% complete (Narrative + Waves). *(Backend gate exists; Overworld Map integration pending)*
    - [x] Allow "Skip Gate" functionality for previously completed (100%) nodes.

- [ ] **2.4 Cinematics**
    - [x] Chapter-end cutscene system for post-boss victory. (`NarrativeReveal.tsx` — full-screen cinematic overlay with staged fade-in, scrollable lore text, star particles, gold title. Lore text DB-driven via `transition_lore_text` column on `chapters`/`books`.)
    - [x] High-fidelity text overlays and atmospheric visual shifts matching book climax.

## 6. Database Schema (Technical Reference)

The following schema supports Story Mode session persistence, dynamic configuration, and meta-progression. (Reference: `db/013_story_mode_state.sql`, `db/014_skill_and_config_refinement.sql`, `db/015_story_mode_additions.sql`)

### 6.1 Global Configuration
Stores admin-tunable settings (e.g., click caps, HP scaling, wave duration).
- `game_configs (key, value_json, description)`

### 6.2 Session Tracking
Tracks active progress in a story scene.
- `player_story_sessions`
    - `id`, `player_id`, `scene_id`, `chapter_id`
    - `current_zone`, `current_wave`
    - `session_gold`
    - `dark_ritual_multiplier` (Chapter-persistent)
    - `narrative_progress_pct`, `narrative_finished`, `required_waves_finished`
    - `is_active`

### 6.3 Narrative Sync
Maps narrative blocks to PNG text assets and calculated delays.
- `scene_narrative_sync (scene_id, paragraph_index, asset_key, word_count)`

### 6.4 In-Session Upgrades
Temporary upgrades purchased with session gold.
- `session_upgrades (session_id, upgrade_type, target_id, level, total_cost_paid, current_multiplier)`

### 6.5 Meta-Progression
Permanent currency earned from Story Mode.
- `player_meta_progression (player_id, elysium_essence, total_essence_earned, spent_essence)`

### 6.6 Content Pipeline Support *(Migration 015)*
- `dev_content_audit` — Logs missing entity sprites/stats for content prioritization.
- `character_skill_levels` — Per-character skill XP and level (bridges 2.2 auto-DPS and 2.3 Idle Training).
