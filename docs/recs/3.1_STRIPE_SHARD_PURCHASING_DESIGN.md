### 1.3 Route: `POST /api/payments/checkout`

**Auth:** Required (Firebase JWT)
**Rate Limit:** 5 req/player/min

```
Request:
{
  "package_id": int
}

Response (200):
{
  "checkout_url": "https://checkout.stripe.com/...",
  "session_id": "cs_test_..."
}

Errors:
  400 — Invalid/inactive package, purchase cap exceeded
  403 — Account has active dispute (purchases blocked)
  429 — Rate limited
```

**Flow:**
1. Check `player.account_flag` — if `'dispute'`, return 403 ("Purchases blocked during active dispute").
2. Validate `package_id` exists and `is_active = TRUE`.
3. If `package.max_purchases_per_player` is set, count existing `completed` orders for this player+package. If at cap, return 400.
4. Look up or create Stripe Customer for this player (§1.5).
5. Generate `idempotency_key` (UUID v4).
6. Create `payment_orders` record with status `pending`.
7. Call `stripe.checkout.Session.create()`:
   - `mode = "payment"`
   - `customer = stripe_customer_id`
   - `payment_method_types`: omit (Stripe auto-enables all: card, Apple Pay, Google Pay, Link)
   - `line_items = [{ price_data: { currency: "usd", unit_amount: package.price_cents, product_data: { name: package.name } }, quantity: 1 }]`
   - `metadata = { player_id, package_id, payment_order_id, idempotency_key }`
   - `success_url = f"{FRONTEND_URL}/shop?session_id={CHECKOUT_SESSION_ID}"`
   - `cancel_url = f"{FRONTEND_URL}/shop"`
   - `expires_at = int(time.time()) + 1800` (30 minutes)
8. Update `payment_orders.stripe_checkout_session_id`.
9. Return checkout URL + session ID.

### 1.4 Route: `POST /api/webhooks/stripe`

**Auth:** None (Stripe signature verification instead)

```
Request: Raw Stripe webhook payload
Headers: Stripe-Signature

Response: 200 (always, after signature verification)

Errors:
  400 — Invalid signature
```

**Flow:**
1. Read raw request body.
2. Call `stripe.Webhook.construct_event(body, sig_header, WEBHOOK_SECRET)`.
3. If verification fails → 400.
4. Log event to `stripe_webhook_events` table (event ID, type, payload).
5. Check for duplicate event ID → skip if already processed.
6. Route to handler by event type:
   - `checkout.session.completed` → `_handle_checkout_completed()`
   - `checkout.session.expired` → `_handle_checkout_expired()`
   - `charge.refunded` → `_handle_charge_refunded()`
   - `charge.dispute.created` → `_handle_dispute_created()`
   - `charge.dispute.closed` → `_handle_dispute_closed()`
   - Others → log and ignore.
7. Return 200.

### 1.5 Stripe Customer Service

```python
async def get_or_create_stripe_customer(player_id: int, db: AsyncSession) -> str:
    """Returns stripe_customer_id. Creates Stripe Customer if needed."""
    player = await db.get(Player, player_id)
    if player.stripe_customer_id:
        return player.stripe_customer_id

    customer = stripe.Customer.create(
        email=player.email,
        metadata={"player_id": str(player_id), "firebase_uid": player.firebase_uid},
        # Email receipts are enabled at the Stripe Dashboard level (Settings > Emails)
    )
    player.stripe_customer_id = customer.id
    db.add(player)
    await db.commit()
    return customer.id
```

### 1.6 Shard Crediting Service

```python
async def credit_shards(
    payment_order_id: int,
    db: AsyncSession
) -> bool:
    """Credits shards for a completed payment. Returns False if already credited."""
    order = await db.get(PaymentOrder, payment_order_id)
    if order.status == "completed":
        return False  # Idempotent — already credited

    package = await db.get(ShardPackage, order.package_id)
    player = await db.get(Player, order.player_id)

    # Calculate total shards
    total_shards = package.total_shards
    if not player.first_purchase_claimed:
        total_shards *= 2  # First-purchase 2x bonus

    # Atomic balance update
    meta = await get_player_meta(order.player_id, db)
    meta.shard_balance += total_shards

    # Audit trail
    txn = ShardTransaction(
        player_id=order.player_id,
        amount=total_shards,
        balance_after=meta.shard_balance,
        source_type="purchase",
        source_id=order.id,
        description=f"Purchased {package.name}" + (" (2x first purchase bonus)" if not player.first_purchase_claimed else "")
    )
    db.add(txn)

    # Update order status
    order.status = "completed"
    order.shards_credited = total_shards
    order.completed_at = datetime.utcnow()

    # Mark first purchase
    if not player.first_purchase_claimed:
        player.first_purchase_claimed = True

    await db.commit()
    return True
```

### 1.7 Shard Debiting Service

```python
def calculate_refund_shards(order: PaymentOrder, refund_amount_cents: int) -> int:
    """Proportional shard debit for partial/full refunds."""
    return math.floor(order.shards_credited * refund_amount_cents / order.price_cents)

async def debit_shards(
    player_id: int,
    amount: int,
    source_type: str,  # "refund" | "dispute"
    source_id: int,
    description: str,
    db: AsyncSession
) -> None:
    """Debits shards. Balance CAN go negative. First-purchase bonus is NOT reset."""
    meta = await get_player_meta(player_id, db)
    meta.shard_balance -= amount

    txn = ShardTransaction(
        player_id=player_id,
        amount=-amount,
        balance_after=meta.shard_balance,
        source_type=source_type,
        source_id=source_id,
        description=description
    )
    db.add(txn)
    await db.commit()
```

Frontend polls this every 3 seconds after Stripe redirect, max 20 attempts (60s).

**Auth:** Required (Firebase JWT)

```

  page: int (default 1)

  source_type: str (optional filter)

Response (200):
{
  "transactions": [
    {
      "id": 1,
      "created_at": "2026-03-10T12:00:00Z",
      "source_type": "purchase",
      "amount": 1100,
      "balance_after": 1100,
      "description": "Purchased Medium Pack",
      "payment_order_id": 42,
      "refund_eligible": true,
      "refund_max_cents": 999,
      "refund_max_shards": 1100
    },
    ...
  ],
  "total": int,
  "page": int,
  "page_size": int
}
```

- `payment_order_id`: Present only for `source_type = 'purchase'`. Needed for refund request linking.
- `refund_eligible`: `true` if purchase is within 14 days AND has unreturned shards. `false` otherwise.
- `refund_max_cents`: Maximum refundable amount in cents (price minus prior refunds).
- `refund_max_shards`: Maximum shards that would be debited on full refund.

7. Stripe redirects to /shop?session_id=cs_test_...

async def reconcile_receipts():
    """Fetch recent Stripe charges and ensure all are credited."""
    charges = stripe.Charge.list(created={"gte": int(time.time()) - 172800})  # 48h

## 4. Error Handling

### 4.1 Stripe API Errors

| Error | Handling |
|:---|:---|
| `stripe.error.CardError` | Not applicable (Checkout handles this) |
| `stripe.error.RateLimitError` | Retry with exponential backoff (max 3 attempts) |
| `stripe.error.InvalidRequestError` | Log error, return 400 to frontend |
| `stripe.error.AuthenticationError` | Log critical alert, return 500 |
| `stripe.error.APIConnectionError` | Retry with exponential backoff |
| `stripe.error.SignatureVerificationError` | Return 400 to Stripe (webhook) |

### 4.2 Database Errors

- All shard balance operations use database-level row locking (`SELECT ... FOR UPDATE`) to prevent race conditions.
- If a transaction fails mid-way, the database transaction rolls back — no partial credits.
