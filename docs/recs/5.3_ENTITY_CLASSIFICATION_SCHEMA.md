# SCHEMA 5.3: Entity Type & Classification Management

Database schema additions for the Entity Classification system. This phase adds **3 new tables**, **3 new columns** on existing tables, **migrates 2 existing columns** from VARCHAR to FK, and **drops 2 old columns**.

**Requirements:** [5.3_ENTITY_CLASSIFICATION.md](5.3_ENTITY_CLASSIFICATION.md) | **Design:** [5.3_ENTITY_CLASSIFICATION_DESIGN.md](5.3_ENTITY_CLASSIFICATION_DESIGN.md)
**Parent:** [5.0_ADMIN_SYSTEMS.md](5.0_ADMIN_SYSTEMS.md) §2

---

## 1. New Table: `entity_types`

Lookup table replacing the free-form `entities.entity_type` VARCHAR(50) field.

```sql
-- Migration: 058_entity_classification.sql

CREATE TABLE entity_types (
    id           SERIAL PRIMARY KEY,
    name         VARCHAR(50)  NOT NULL UNIQUE,
    display_name VARCHAR(100) NOT NULL,
    description  TEXT,
    color_hex    VARCHAR(7),
    sort_order   INTEGER      NOT NULL DEFAULT 0,
    created_at   TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at   TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);

-- Auto-update trigger
CREATE TRIGGER update_entity_types_modtime
    BEFORE UPDATE ON entity_types
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();
```

### 3.1 Column Reference

| Column | Type | Nullable | Default | FK | Description |
|:---|:---|:---|:---|:---|:---|
| `id` | serial | NO | auto | — | Primary key |
| `name` | varchar(50) | NO | — | — | System key (lowercase, unique). e.g., "grounded_melee" |
| `display_name` | varchar(100) | NO | — | — | Admin-facing label |
| `description` | text | YES | NULL | — | Description of the visual behavior |
| `animation_config` | jsonb | NO | {} | — | Animation configuration (see §3.2) |
| `sort_order` | integer | NO | 0 | — | Display ordering |
| `created_at` | timestamptz | NO | NOW() | — | Created timestamp |
| `updated_at` | timestamptz | NO | NOW() | — | Updated timestamp |

### 3.2 `animation_config` JSONB Structure

```json
{
  "y_offset": 0,
  "movement_pattern": "walk",
  "attack_animation": "melee_swing",
  "attack_vfx": null,
  "idle_animation": "idle_bounce",
  "speed_modifier": 1.0
}
```

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| `y_offset` | integer | 0 | Vertical pixel offset from ground (negative = higher) |
| `movement_pattern` | string | "walk" | Options: "walk", "hover", "teleport", "stationary", "burrow" |
| `attack_animation` | string | "melee_swing" | Options: "melee_swing", "projectile", "spell_cast", "dive_attack", "area_blast" |
| `attack_vfx` | string | null | Optional VFX overlay key during attack |
| `idle_animation` | string | "idle_bounce" | Options: "idle_bounce", "float", "pulse", "shimmer" |
| `speed_modifier` | float | 1.0 | Movement speed multiplier relative to base |

**Note:** These values define the data contract. Actual rendering integration is deferred (C_BANNER_ANIMATION_SYSTEM). New keys can be added without migration since the field is JSONB.

## 4. Modified Table: `attack_types`

Add two new columns for visual behavior mapping and stat multipliers.

```sql
-- Add visual_behavior_id FK
ALTER TABLE attack_types
    ADD COLUMN visual_behavior_id INTEGER REFERENCES visual_behaviors(id) ON DELETE SET NULL;

-- Add stat_multipliers JSONB
ALTER TABLE attack_types
    ADD COLUMN stat_multipliers JSONB;
```

### 4.1 New Columns

| Column | Type | Nullable | Default | FK | Description |
|:---|:---|:---|:---|:---|:---|
| `visual_behavior_id` | integer | YES | NULL | visual_behaviors(id) SET NULL | Associated visual behavior for banner rendering |

## 5. Modified Table: `entities`

Replace VARCHAR classification columns with FK references, then drop old columns.

```sql
-- Step 1: Add new FK columns
ALTER TABLE entities
    ADD COLUMN entity_type_id   INTEGER REFERENCES entity_types(id) ON DELETE RESTRICT,
    ADD COLUMN entity_family_id INTEGER REFERENCES entity_families(id) ON DELETE SET NULL;

-- Step 2: Populate entity_type_id from existing entity_type string
UPDATE entities e
SET entity_type_id = et.id
FROM entity_types et
WHERE e.entity_type = et.name;

-- Step 3: Make entity_type_id NOT NULL (all rows now have a value)
ALTER TABLE entities
    ALTER COLUMN entity_type_id SET NOT NULL;

-- Step 4: entity_family_id stays NULL for now (no entity_family values exist in DB)
-- When families are created, admins assign entities via the UI.

-- Step 5: Drop old columns
ALTER TABLE entities DROP COLUMN entity_type;
ALTER TABLE entities DROP COLUMN entity_family;

-- Step 6: Drop old index on entity_family (now replaced by FK index)
-- idx_entities_family was on the old VARCHAR column — automatically dropped with column

-- Step 7: Add indexes on new FK columns
CREATE INDEX idx_entities_entity_type_id ON entities(entity_type_id);
CREATE INDEX idx_entities_entity_family_id ON entities(entity_family_id);
```

### 5.1 Updated Column Reference (entities table — changed columns only)

| Column | Type | Nullable | Default | FK | Description |
|:---|:---|:---|:---|:---|:---|
| `entity_type_id` | integer | NO | — | entity_types(id) RESTRICT | Entity classification type (replaces old VARCHAR `entity_type`) |
| `entity_family_id` | integer | YES | NULL | entity_families(id) SET NULL | Entity family grouping (replaces old VARCHAR `entity_family`) |

**FK behavior:**
- `entity_type_id` uses `ON DELETE RESTRICT` — cannot delete a type while entities reference it.
- `entity_family_id` uses `ON DELETE SET NULL` — deleting a family nulls the reference on entities.

## 7. SQLModel Definitions

### 7.1 New Models (`backend/models/classification.py`)

```python
from typing import Optional
from datetime import datetime, timezone
from sqlmodel import SQLModel, Field
from sqlalchemy import Column
from sqlalchemy.dialects.postgresql import JSONB


class EntityType(SQLModel, table=True):
    __tablename__ = "entity_types"

    id: Optional[int] = Field(default=None, primary_key=True)
    name: str = Field(max_length=50, unique=True)
    display_name: str = Field(max_length=100)
    description: Optional[str] = None
    color_hex: Optional[str] = Field(default=None, max_length=7)
    sort_order: int = Field(default=0)
    created_at: Optional[datetime] = None
    updated_at: Optional[datetime] = None


class EntityFamily(SQLModel, table=True):
    __tablename__ = "entity_families"

    id: Optional[int] = Field(default=None, primary_key=True)
    name: str = Field(max_length=100, unique=True)
    display_name: str = Field(max_length=100)
    description: Optional[str] = None
    icon_key: Optional[str] = Field(default=None, max_length=100)
    lore_reference: Optional[str] = None
    base_stat_template: Optional[dict] = Field(default=None, sa_column=Column(JSONB))
    sort_order: int = Field(default=0)
    created_at: Optional[datetime] = None
    updated_at: Optional[datetime] = None


class VisualBehavior(SQLModel, table=True):
    __tablename__ = "visual_behaviors"

    id: Optional[int] = Field(default=None, primary_key=True)
    name: str = Field(max_length=50, unique=True)
    display_name: str = Field(max_length=100)
    description: Optional[str] = None
    animation_config: dict = Field(default_factory=dict, sa_column=Column(JSONB, nullable=False, server_default="'{}'::jsonb"))
    sort_order: int = Field(default=0)
    created_at: Optional[datetime] = None
    updated_at: Optional[datetime] = None
```
