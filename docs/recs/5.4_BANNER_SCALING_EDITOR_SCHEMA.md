# SCHEMA 5.4: Banner & Scaling Editor (Visual & Difficulty Tuning)

Database schema additions for the Banner & Scaling Editor. This phase adds **4 new tables**, **1 new column** on an existing table (`visual_behaviors`), **1 new FK column** on an existing table (`books`), and **4 new game_configs keys**.

**Requirements:** [5.4_BANNER_SCALING_EDITOR.md](5.4_BANNER_SCALING_EDITOR.md) | **Design:** [5.4_BANNER_SCALING_EDITOR_DESIGN.md](5.4_BANNER_SCALING_EDITOR_DESIGN.md)
**Parent:** [5.0_ADMIN_SYSTEMS.md](5.0_ADMIN_SYSTEMS.md) §2

## 1. Modified Table: `visual_behaviors`

Add `stat_weights` JSONB column for visual weight configuration per behavior.

```sql
-- Migration: 059_banner_scaling_editor.sql

ALTER TABLE visual_behaviors
    ADD COLUMN stat_weights JSONB;
```

### 1.1 New Column

| Column | Type | Nullable | Default | FK | Description |
|:---|:---|:---|:---|:---|:---|
| `stat_weights` | jsonb | YES | NULL | — | Per-behavior stat-to-visual weight mapping with clamps (see §1.2) |

### 1.2 `stat_weights` JSONB Structure

```json
{
  "size": {"strength": 0.6, "agility": 0.2, "intelligence": 0.2},
  "speed": {"strength": 0.1, "agility": 0.7, "intelligence": 0.2},
  "vfx_intensity": {"strength": 0.1, "agility": 0.1, "intelligence": 0.8},
  "clamps": {"size": [0.5, 2.5], "speed": [0.3, 1.5], "vfx_intensity": [0.0, 1.0]}
}
```

| Key | Type | Description |
|-----|------|-------------|
| `size` | object | STR/AGI/INT weights (0.0–1.0) for sprite scale factor |
| `speed` | object | STR/AGI/INT weights (0.0–1.0) for movement speed modifier |
| `vfx_intensity` | object | STR/AGI/INT weights (0.0–1.0) for VFX particle density/brightness |
| `clamps` | object | Per-property `[min, max]` bounds to prevent extreme visual values |

## 2. New Table: `wave_presets`

Named, reusable wave configuration templates stored as JSONB blobs.

```sql
CREATE TABLE wave_presets (
    id          SERIAL PRIMARY KEY,
    name        VARCHAR(100) NOT NULL UNIQUE,
    description TEXT,
    config      JSONB        NOT NULL DEFAULT '{}'::jsonb,
    is_default  BOOLEAN      NOT NULL DEFAULT FALSE,
    sort_order  INTEGER      NOT NULL DEFAULT 0,
    created_at  TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at  TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);

CREATE TRIGGER update_wave_presets_modtime
    BEFORE UPDATE ON wave_presets
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();
```

### 2.1 Column Reference

| Column | Type | Nullable | Default | FK | Description |
|:---|:---|:---|:---|:---|:---|
| `id` | serial | NO | auto | — | Primary key |
| `name` | varchar(100) | NO | — | — | Preset name (unique). e.g., "Standard", "Dense Combat" |
| `description` | text | YES | NULL | — | Description of the preset's purpose |
| `config` | jsonb | NO | {} | — | Wave configuration blob (see §2.2) |
| `is_default` | boolean | NO | FALSE | — | Whether this is the global default preset (at most one true) |
| `sort_order` | integer | NO | 0 | — | Display ordering |
| `created_at` | timestamptz | NO | NOW() | — | Created timestamp |
| `updated_at` | timestamptz | NO | NOW() | — | Updated timestamp |

### 2.2 `config` JSONB Structure

```json
{
  "max_enemies_per_wave": 5,
  "wave_count": 10,
  "spawn_interval_ms": 2000,
  "scaling_factor": 1.0,
  "hp_multiplier": 1.0,
  "gold_multiplier": 1.0,
  "spawn_pattern": "uniform"
}
```

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| `max_enemies_per_wave` | integer | 5 | Maximum enemies alive simultaneously |
| `wave_count` | integer | 10 | Number of waves per scene |
| `spawn_interval_ms` | integer | 2000 | Milliseconds between enemy spawns |
| `scaling_factor` | float | 1.0 | General difficulty scaling multiplier |
| `hp_multiplier` | float | 1.0 | Enemy HP multiplier |
| `gold_multiplier` | float | 1.0 | Gold reward multiplier |
| `spawn_pattern` | string | "uniform" | Enemy spawn distribution: "uniform", "front_loaded", "crescendo", "random" |

All fields optional within the JSONB — missing fields fall through to hardcoded defaults at runtime.

## 3. New Table: `wave_preset_assignments`

Links wave presets to books or chapters for the inheritance chain.

```sql
CREATE TABLE wave_preset_assignments (
    id             SERIAL PRIMARY KEY,
    wave_preset_id INTEGER      NOT NULL REFERENCES wave_presets(id) ON DELETE CASCADE,
    book_id        INTEGER               REFERENCES books(id) ON DELETE CASCADE,
    chapter_id     INTEGER               REFERENCES chapters(id) ON DELETE CASCADE,
    created_at     TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at     TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    CONSTRAINT wpa_exactly_one_target CHECK (
        (book_id IS NOT NULL AND chapter_id IS NULL) OR
        (book_id IS NULL AND chapter_id IS NOT NULL)
    )
);

-- Each book can have at most one wave preset assignment
CREATE UNIQUE INDEX idx_wpa_unique_book ON wave_preset_assignments(book_id) WHERE book_id IS NOT NULL;
-- Each chapter can have at most one wave preset assignment
CREATE UNIQUE INDEX idx_wpa_unique_chapter ON wave_preset_assignments(chapter_id) WHERE chapter_id IS NOT NULL;
-- Index for preset lookups
CREATE INDEX idx_wpa_wave_preset_id ON wave_preset_assignments(wave_preset_id);

CREATE TRIGGER update_wave_preset_assignments_modtime
    BEFORE UPDATE ON wave_preset_assignments
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();
```

### 3.1 Column Reference

| Column | Type | Nullable | Default | FK | Description |
|:---|:---|:---|:---|:---|:---|
| `id` | serial | NO | auto | — | Primary key |
| `wave_preset_id` | integer | NO | — | wave_presets(id) CASCADE | The wave preset being assigned |
| `book_id` | integer | YES | NULL | books(id) CASCADE | Book this preset applies to (mutually exclusive with chapter_id) |
| `chapter_id` | integer | YES | NULL | chapters(id) CASCADE | Chapter this preset applies to (mutually exclusive with book_id) |
| `created_at` | timestamptz | NO | NOW() | — | Created timestamp |
| `updated_at` | timestamptz | NO | NOW() | — | Updated timestamp |

**Constraints:**
- CHECK: exactly one of `book_id` or `chapter_id` must be non-null.
- Unique partial indexes: each book and each chapter can have at most one assignment.

## 4. New Table: `difficulty_curves`

Named difficulty curve profiles with multi-dimension per-chapter multipliers.

```sql
CREATE TABLE difficulty_curves (
    id          SERIAL PRIMARY KEY,
    name        VARCHAR(100) NOT NULL UNIQUE,
    description TEXT,
    curve_data  JSONB        NOT NULL DEFAULT '{}'::jsonb,
    is_default  BOOLEAN      NOT NULL DEFAULT FALSE,
    sort_order  INTEGER      NOT NULL DEFAULT 0,
    created_at  TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at  TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);

CREATE TRIGGER update_difficulty_curves_modtime
    BEFORE UPDATE ON difficulty_curves
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();
```

### 4.1 Column Reference

| Column | Type | Nullable | Default | FK | Description |
|:---|:---|:---|:---|:---|:---|
| `id` | serial | NO | auto | — | Primary key |
| `name` | varchar(100) | NO | — | — | Curve name (unique). e.g., "Standard Ramp", "Steep Ramp" |
| `description` | text | YES | NULL | — | Description of the curve's behavior |
| `curve_data` | jsonb | NO | {} | — | Chapter position → multipliers mapping (see §4.2) |
| `is_default` | boolean | NO | FALSE | — | Whether this is the global default curve (at most one true) |
| `sort_order` | integer | NO | 0 | — | Display ordering |
| `created_at` | timestamptz | NO | NOW() | — | Created timestamp |
| `updated_at` | timestamptz | NO | NOW() | — | Updated timestamp |

### 4.2 `curve_data` JSONB Structure

```json
{
  "1": {"hp": 1.0, "gold": 1.0, "wave_density": 1.0, "spawn_speed": 1.0},
  "2": {"hp": 1.1, "gold": 1.05, "wave_density": 1.1, "spawn_speed": 1.0},
  "3": {"hp": 1.25, "gold": 1.1, "wave_density": 1.2, "spawn_speed": 0.95}
}
```

| Key | Type | Description |
|-----|------|-------------|
| `hp` | float | Enemy HP multiplier for this chapter position |
| `gold` | float | Gold reward multiplier |
| `wave_density` | float | Enemies per wave multiplier (applied on top of wave preset) |
| `spawn_speed` | float | Spawn interval multiplier (< 1.0 = faster spawns) |

Chapters beyond the last defined key use the last entry's values.
