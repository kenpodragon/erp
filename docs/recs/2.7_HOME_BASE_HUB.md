# REC 2.7: Home Base Hub (Meta-Progression & Collections)

This document defines the complete requirements for the Home Base Hub — the player's persistent sanctum within the Tower of Elysium. It covers four major terminal systems, the artifact collection framework, and all associated admin tooling.

**Design:** [2.7_HOME_BASE_HUB_DESIGN.md](2.7_HOME_BASE_HUB_DESIGN.md) | **Schema:** [2.7_HOME_BASE_HUB_SCHEMA.md](2.7_HOME_BASE_HUB_SCHEMA.md)

---

## 1. Overview & Scope

### 1.1 Purpose
The Home Base Hub is the primary meta-progression dashboard. It surfaces:
- Narrative progress and lore exploration (Akashic Log)
- Artifact collection with permanent passive bonuses (Relic Gallery)
- Competitive standings and player identity (Hall of Echoes)
- Long-term challenge tracking with rewards (Achievement Matrix)

### 1.2 Scope Boundaries
- **In Scope:** The four Hub terminals, artifact system (curated + generated), achievement system (90+ challenges), Idle Training milestone rewards, leaderboard expansion, and admin tooling.
- **Out of Scope:** Player-to-player trading, auction house, Elysium Essence economy rework, and NPC vendor mechanics. These are deferred to **Phase 3.0 (Marketplace & Premium)**.
- **Dependencies:** Builds on existing Home Base view (2.1), Dream Item system (2.4.2), Discovery system (2.6.2), and Idle Training (2.3).

### 1.3 Aesthetic: MR2 Base + Terminal Accents
- **Base:** "Magic Research 2" clean dark panel styling consistent with the rest of the game (established in 2.6.3).
- **Terminal Accents:** Subtle CRT scanline overlay on terminal headers, monospace font (Fira Code / JetBrains Mono) for data displays, amber (#ffb000) accent color for highlights and active states.
- **Animation:** All terminal effects must respect the Reduce Motion setting (2.6.0). When reduced, scanlines and flicker are disabled; static borders/colors replace animated accents.

## 2. Terminal 1: The Akashic Log (Personal Journal)

A searchable record of every story beat the player has encountered.

### 2.1 Narrative Database
- [x] **Log Entries:** Automatically populated upon completing story beats in Story Mode.
- [x] **Structure:** Organized by Book > Chapter > Scene > Beat.
- [x] **Hidden Lore:** Story beats may contain `hidden_lore_text` that is only revealed when the player's Intelligence stat meets or exceeds a `lore_intelligence_threshold` on the beat. If the threshold is not met, display a locked indicator ("Requires Intelligence XX to decipher").
- [x] **Beat Detail View:** Clicking a beat entry expands it inline to show the full text, any hidden lore (if unlocked), and metadata (first completed date, times revisited).

### 2.2 Search & Discovery
- [x] **Filtering:** Filter by Book number or Chapter title.
- [x] **Keyword Search:** Full-text search across all unlocked story beat content. Results highlight matching keywords in context. Search is client-side against the fetched log payload (no server-side full-text index needed for MVP).
- [x] **Narrative Completion Indicator:** Per-book and per-chapter progress bars showing `(unlocked beats / total beats) * 100%`. Displayed as a percentage badge on each book/chapter header row.
- [x] **"New" Badge:** Beats unlocked since the player's last visit to the Akashic Log are marked with a "New" indicator. Cleared on view.

### 2.3 Technical Notes
- Backend provides `/api/game/home-base/akashic-log` returning all unlocked beats organized by book/chapter/scene hierarchy, including hidden lore eligibility based on current Intelligence stat.
- Client-side keyword search using `String.includes()` or similar — no server-side search endpoint needed for MVP.

## 3. Terminal 2: Relic Gallery (Artifacts & Collections)

A visual collection display for permanent passive-bonus artifacts. Artifacts are distinct from inventory items: they never expire, provide permanent buffs, cannot be duplicated, and have their own dedicated gallery.

### 3.1 Artifact System Overview

There are two categories of artifacts:

#### 3.1.1 Curated Artifacts (~50 artifacts)
- **Source:** Tied to specific bosses, chapter completions, or rare spawns.
- **Power Level:** Significantly powerful with multiple stat bonuses and unique effects.
- **Rarity Tiers:** Each curated artifact exists in 5 rarity tiers (Common, Uncommon, Rare, Epic, Cosmic). Higher difficulty / repeated farming yields higher rarity versions.
- **Drop Rate:** Extremely rare. Drop chance is configurable per artifact via `game_configs`.
- **Source Hint:** Each artifact displays where it can be obtained (e.g., "Drops from: Chapter 3 Boss — The Pallid Mask") so players can target-farm.
- **Rare Spawn Exclusives:** A small subset (~5-8) of curated artifacts drop only from random rare spawn entities, obtainable at any stage.
- **Rarity Upgrade:** If a player obtains a higher-rarity version of an artifact they already own, the new version replaces the old. Stats scale with rarity tier.

#### 3.1.2 Generated Artifacts
- **Source:** Random drops from any Story Mode completion, boss kills, or chapter mastery.
- **Power Level:** Noticeably weaker than curated artifacts. Very few stats even at max rarity.
- **Generation:** Uses a simplified version of the Dream Item generator (prefix + type + suffix) but with a reduced stat pool and lower base ranges.
- **Rarity Tiers:** Same 5 tiers, but stat scaling is minimal (max rarity generated artifact ~= common curated artifact in power).
- **No Duplicates:** If a player generates an artifact with an identical `artifact_code`, it is discarded (no duplicate entries). Higher rarity replaces lower (same as curated).

### 3.2 Collection Display
- [x] **Grid Layout:** Artifacts displayed as 64x64 pixel art icons with a glowing rarity border (color matches rarity tier).
- [x] **Filtering:** Filter by source type (Boss, Chapter, Rare Spawn, Generated), rarity tier, and effect type.
- [x] **Sorting:** Sort by rarity, acquisition date, or alphabetical.
- [x] **Collection Progress:** "X / Y Curated Artifacts Collected" counter prominently displayed. Per-rarity breakdown available on hover/click.
- [x] **Empty Slots:** Undiscovered curated artifacts show as silhouetted placeholders with a "???" name and their source hint visible.

### 3.3 Artifact Inspection Modal
- [x] **Lore Inspection:** Clicking an artifact opens a modal with:
  - A centered, larger (128x128 or 192x192) artifact icon with a subtle rotation/glow animation (CSS transform, respects Reduce Motion).
  - Artifact name, rarity badge, and lore description text.
  - Stat bonuses listed (e.g., "+3 Strength", "+1.5% Crit Chance").
  - Source information ("Obtained from: Chapter 5 Boss — Void Entity" or "Generated from: Scene 12 Completion").
  - Acquisition date.

### 3.4 Artifact Synergies & Passive Bonuses
- [x] **Global Application:** Artifact bonuses are permanently applied to the player's character stats. They are included in `recalculate_character_stats()` alongside idle skill contributions and class affinities.
- [x] **Stacking:** All artifact bonuses (curated and generated) stack additively.
- [x] **Combat/Training Integration:** Artifact stat bonuses flow through the existing `character_stats` computation pipeline. Visible in HeroStats panel via Relic Power badge (compact gem icon, click-to-expand per-stat breakdown).
- **Synergy Sets (Deferred):** Artifact set bonuses are deferred to a future phase. The schema should include a `synergy_set_id` FK for future use, but no synergy logic is implemented in 2.7.

### 3.5 Admin Artifact Editor
- [x] **Curated Artifact CRUD:** Create, edit, and delete curated artifact definitions. Fields: name, description, lore text, icon sprite key, base stats per rarity tier, source type/ID, drop chance, synergy set assignment.
- [x] **Generated Artifact Config:** Edit generation parameters (stat pool, base ranges, rarity weights per book) via `game_configs`. Collapsible panel in ArtifactEditor.tsx for 7 keys.
- [x] **Drop Rate Tuning:** Adjust per-artifact and global artifact drop rates from the admin panel.
- [x] **Bulk Assignment:** Assign curated artifacts to bosses/chapters/rare spawns in bulk.

## 4. Terminal 3: The Hall of Echoes (Leaderboards)

Competitive standings for all players.

### 4.1 Competition Categories
- [x] **The Vanguard (Progression):** Rank by furthest reached Scene.
- [x] **The Alchemist (Essence):** Rank by total lifetime Elysium Essence accumulated.
- [x] **The Swift (Speedruns):** Fastest completion times for specific boss scenes. Uses `player_scene_records.best_time_seconds`. Initially covers chapter bosses only.
- [x] **The Scholar (Lore):** Total number of unique story beats unlocked. Calculated by counting `story_beats` belonging to scenes the player has completed (via `player_scene_records`).

### 4.2 Leaderboard Display
- [x] **Paginated List:** Top 100 per category with the player's own rank highlighted if not in top 100.
- [x] **Static Rank Card:** Each leaderboard row displays: Rank #, Player Alias, Character Class icon, Character Level, equipped Title (if any), and the category-specific metric value.
- [x] **Tiered Visual Badges:**
  - Cosmic: Top 1% (animated border glow, respects Reduce Motion).
  - Gold: Top 5%.
  - Silver: Top 15%.
  - Bronze: Top 30%.
  - Badges are displayed as small icons next to the player's rank.
- [x] **Refresh Rate:** Leaderboard data is cached server-side and refreshed every 5 minutes (configurable via `game_configs`).

### 4.3 Idle Training Milestone Display
- [x] **Cross-ref 2.3 (Idle Milestones):** 5th "Milestones" tab in HallOfEchoes.tsx. 4x4 grid (4 idle skills x L25/50/75/99). Pulls current levels from `/api/game/training/skills`. Checkmarks for completed, percentage for in-progress. Essence reward display per tier.

## 5. Terminal 4: Achievement Matrix

A comprehensive challenge tracker with 90+ achievements spanning all game systems.

### 5.1 Achievement Categories

#### 5.1.1 Combat Achievements (~30)
Tracked via `player_story_sessions`, `boss_completions`, `player_scene_records`, and `activity_events`.
- **Kill Count:** "Defeat X enemies" (thresholds: 100, 500, 1K, 5K, 10K, 50K, 100K).
- **Boss Slayer:** "Defeat [specific boss] for the first time."
- **Damage Dealer:** "Deal X total damage in a single session" (thresholds: 100K, 1M, 10M, 100M).
- **Wave Surfer:** "Reach wave X in a single session" (thresholds: 50, 100, 250, 500).
- **Flawless:** "Complete a scene without dying." (Tracked via `player_story_sessions.deaths == 0`. Client sends `deaths` count at `/complete`.)
- **Speed Kills:** "Defeat a chapter boss in under X seconds."
- **Dark Ritual Master:** "Reach Dark Ritual multiplier X" (thresholds: 5x, 10x, 25x, 50x).

#### 5.1.2 Narrative Achievements (~20)
Tracked via story beat unlocks and chapter/book completions. The game has 138 chapters (90 + 23 + 25) across 3 books, 724 scenes, and 2041 beats.
- **Chapter Milestones:** "Complete X chapters" (thresholds: 10, 25, 50, 100, all 138). Tiered, not one-per-chapter.
- **Book Complete:** "Complete Book X" (3 achievements).
- **Lore Scholar:** "Unlock X% of all story beats" (thresholds: 25%, 50%, 75%, 100%).
- **Hidden Knowledge:** "Unlock X hidden lore entries" (thresholds: 5, 15, 30, all).
- **Completionist:** "Achieve 100% narrative completion across all books."

#### 5.1.3 Economics Achievements (~15)
Tracked via session gold, Essence balance, and inventory.
- **Gold Hoarder:** "Accumulate X gold in a single Story Mode run" (thresholds: 10K, 100K, 1M, 10M).
- **Essence Collector:** "Accumulate X total lifetime Essence" (thresholds: 100, 1K, 10K, 100K).
- **Collector:** "Own X unique artifacts" (thresholds: 5, 15, 30, 50).
- **Full Set:** "Complete an artifact synergy set."
- **Geared Up:** "Fill all 16 gear slots with equipment."
- **Cosmic Touch:** "Obtain a Cosmic rarity item."

#### 5.1.4 Idle Training Achievements (~22)
Tracked via `character_skill_levels`. Includes the cross-ref 2.3 milestone rewards. The DB has **4 idle training skills** (Attack, Magic, Lore, Precision — those with `idle_flavor_title`).
- **Milestone Tiers:** For each idle skill: "Reach Level 25 / 50 / 75 / 99 in [Skill Name]." These are the primary milestone rewards from 2.3. (4 skills × 4 tiers = 16 achievements)
- **Jack of All Trades:** "Reach Level 25 in all idle skills."
- **Master of All:** "Reach Level 50 in all idle skills."
- **Grandmaster:** "Reach Level 99 in all idle skills."
- **Active Trainer:** "Complete X active training click sessions" (thresholds: 10, 50, 100).

#### 5.1.5 Discovery Achievements (~10)
Tracked via `player_entity_discovery` and `player_discovery_log`.
- **Entity Hunter:** "Discover X unique entities" (thresholds: 10, 25, 50, all).
- **Rare Find:** "Encounter a rare spawn entity."
- **Codex Rank:** "Achieve SS rank on X entities" (thresholds: 1, 5, 15, all).
- **Full Library:** "Discover all skills in the Skill Library."

### 5.2 Achievement Rewards
- [x] **Elysium Shards:** Small premium currency grants for major milestones (configurable per achievement). Range: 1-50 Shards depending on difficulty.
- [x] **Titles:** Prefix/Suffix titles for the player's display name. Examples:
  - "[Name] the Awakened" (Complete Book 1)
  - "Grandmaster [Name]" (Level 99 all idle skills)
  - "[Name], Void Walker" (Defeat all Book 2 bosses)
  - "Scholar [Name]" (100% lore completion)
- [x] **Essence Grants:** Flat Elysium Essence rewards for Idle Training milestones (Level 25: 250 Essence, Level 50: 500 Essence, Level 75: 1000 Essence, Level 99: 2500 Essence).
- [ ] **Visual Badges:** Achievement icons displayed on the player's leaderboard rank card and profile.

### 5.3 Achievement UI
- [x] **Grid Layout:** Achievements displayed in a categorized grid. Each cell shows: icon, title, progress bar (X/Y), and completion state (locked/in-progress/completed).
- [x] **Category Tabs:** Filter by Combat, Narrative, Economics, Idle Training, Discovery.
- [x] **Sorting:** Sort by completion %, recently completed, or category.
- [x] **Completion Summary:** Header shows "X / Y Achievements Completed" with per-category breakdown.
- [x] **Toast Notification:** When an achievement is completed during gameplay, show a toast notification with the achievement name and reward in PostBattleSummary.
- [x] **"New" Badge:** Recently completed achievements highlighted until viewed in the Matrix.

### 5.4 Admin Achievement Editor
- [x] **Achievement CRUD:** Create, edit, deactivate achievements. Fields: name, description, category, icon, tracking_type, threshold, rewards (shards, title, essence, badge).
- [x] **Bulk Seeding:** Migration 047 seeds 90+ achievements from structured SQL definition.
- [x] **Player Override:** Manually grant or revoke achievements for specific players (support use case).
- [x] **Analytics:** View completion rates per achievement (% of players who've earned it).

## 6. Cross-Cutting Requirements

### 6.1 Consolidated Home Base API
- [x] **Payload Endpoint:** `GET /api/game/home-base/summary` returns a consolidated payload with:
  - Akashic Log: recent unlocks count, total completion %.
  - Relic Gallery: total artifacts owned, curated progress (X/Y), new artifacts since last visit.
  - Hall of Echoes: player's rank in each category, badge tier.
  - Achievement Matrix: total completed, recently earned, new count.
- [x] **Per-Terminal Endpoints:** Each terminal has its own detailed data endpoint for lazy loading:
  - `GET /api/game/home-base/akashic-log` — full beat log with hidden lore eligibility.
  - `GET /api/game/home-base/artifacts` — player's artifact collection.
  - `GET /api/game/home-base/leaderboard/{category}` — paginated leaderboard.
  - `GET /api/game/home-base/achievements` — full achievement list with progress.

### 6.2 Notifications & Badges
- [x] **Hub Badge Count:** The main navigation shows a badge count on the Home Base icon indicating total "new" items across all terminals (new beats + new artifacts + new achievements).
- [x] **Clear on Visit:** "New" flags are cleared when the player visits the specific terminal.

### 6.3 Server Authority
- All unlock states (beats, artifacts, achievements, titles) are server-authoritative.
- Client never determines whether an achievement is earned — the server evaluates and grants.
- Achievement evaluation runs at session boundaries (session complete, boss kill, level up, chapter completion) — not mid-combat or on a polling timer. Achievements earned appear in the post-battle summary.

### 6.4 Performance
- Home base summary endpoint should respond in <200ms.
- Leaderboards use server-side caching (5-minute TTL configurable via `game_configs`).
- Achievement evaluation runs at session boundaries (session `/complete`, level-up, chapter completion), not mid-combat.
- Artifact bonus computation is cached in `character_stats` and only recalculated on artifact acquisition/upgrade.
