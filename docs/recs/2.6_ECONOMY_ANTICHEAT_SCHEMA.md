# REC 2.6: Economy, Anti-Cheat & Discovery — Schema Specification

This document defines the database migrations and schema updates required for the Economy, Anti-Cheat, and Discovery systems.

---

## 1. New Tables

### 1.1 Chat System
```sql
CREATE TABLE chat_messages (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    player_id INTEGER REFERENCES players(id) ON DELETE CASCADE,
    channel_id VARCHAR(50) NOT NULL DEFAULT 'global',
    content TEXT NOT NULL,
    is_system BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_chat_messages_channel_created ON chat_messages(channel_id, created_at DESC);
```

## 3. Atomic JSONB Update Functions

To prevent race conditions during simultaneous updates (Story Mode vs. Active Training), we use atomic `jsonb_set` and `||` operations.

### 3.1 Increment Registry Kills
```sql
CREATE OR REPLACE FUNCTION increment_player_registry_kill(
    p_player_id INTEGER, 
    p_entity_id TEXT
) RETURNS VOID AS $$
BEGIN
    UPDATE player_progress
    SET registry_kills = jsonb_set(
        registry_kills, 
        ARRAY[p_entity_id], 
        jsonb_build_object(
            'encounters', COALESCE((registry_kills->p_entity_id->>'encounters')::int, 0) + 1,
            'kills', COALESCE((registry_kills->p_entity_id->>'kills')::int, 0) + 1
        ), 
        true
    )
    WHERE player_id = p_player_id;
END;
$$ LANGUAGE plpgsql;
```

### 3.2 Add Registry Discovery
```sql
CREATE OR REPLACE FUNCTION add_player_registry_discovery(
    p_player_id INTEGER, 
    p_discovery_type TEXT, 
    p_discovery_id TEXT
) RETURNS VOID AS $$
BEGIN
    UPDATE player_progress
    SET registry_discoveries = jsonb_set(
        registry_discoveries, 
        ARRAY[p_discovery_type], 
        (registry_discoveries->p_discovery_type) || jsonb_build_array(p_discovery_id), 
        true
    )
    WHERE player_id = p_player_id 
    AND NOT (registry_discoveries->p_discovery_type @> jsonb_build_array(p_discovery_id));
END;
$$ LANGUAGE plpgsql;
```
