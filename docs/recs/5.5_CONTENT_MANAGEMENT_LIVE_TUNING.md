# REC 5.5: Content Management & Live Tuning

This document defines the complete requirements for the Content Management & Live Tuning system — specialized admin interfaces for tuning drop rates, skill balance, economy parameters, and a reorganization of the GameConfigs page into a purpose-built tuning hub.

## 1. Overview & Scope

### 1.1 Purpose
Section 5.5 transforms the existing generic GameConfigs key-value editor into a purpose-built game tuning hub with specialized views for the most complex tuning scenarios. After this phase, a non-developer game admin should be able to:

- Adjust drop rates for artifacts, items, and rare spawns with visual distribution previews
- Review skill balance by seeing computed DPS at various levels alongside global coefficients
- Tune the Idle Training economy (essence thresholds, XP curves, salvage rates) with a reactive step-function visualization
- Navigate all 137+ game_configs keys via organized category tabs with type-aware inputs and inline help

**Platform vision:** All tuning is config-driven via `game_configs`. The specialized views are presentation layers over the same data — no parallel config stores.

### 1.2 Existing Foundation

| System | Current State | What 5.5 Does |
|--------|--------------|----------------|
| `game_configs` table (2.4) | 137 keys across 18 categories pre-5.4 (141 keys, 19 categories after 5.4 adds 4 `waves` keys), generic key-value JSON editor | Reorganize into tabbed categories with type-aware inputs + 3 specialized tabs |
| `GameConfigs.tsx` (admin) | Flat table view, JSON value editing, search bar | Extend with category tabs, smart inputs, specialized panels |
| `skills` table | 9+ skills with `base_cooldown_seconds`, `base_cost_gold`, `cost_scaling_factor`, `benefits_json` | Read-only cross-reference view in Skill Balance tab |
| `skill_actions` table | Per-skill actions with `interval_ms`, `xp_per_action` | Included in Skill Balance cross-reference |
| Drop rate keys | `artifact_gen_drop_chance_*`, `artifact_rarity_weight_book_*`, `rarity_weight_book_*`, `rare_spawn_base_chance`, etc. | Grouped in Drop Rate Manager with distribution previews |
| Economy keys | `gold_to_essence_*`, `idle_essence_*`, `salvage_*`, subscription boosts | Grouped in Economy Tuning with step-function visualization |

### 1.3 Scope Boundaries
- **In Scope:** Drop Rate Manager (global view with distribution previews), Skill Balance cross-reference (read-only skills + computed DPS), Economy Tuning panel (essence XP curve visualization, salvage rates), GameConfigs category reorganization (tabs, type-aware inputs, search).
- **Out of Scope:** HP/Gold Scaler (covered by 5.4 Scaling Preview + Difficulty Presets). Narrative Timing Editor (single key `default_player_wpm` stays in GameConfigs `ui` category). Per-scene/chapter drop rate overrides (not needed). Skill data editing (stays in ContentEditor). New schema tables — all tuning uses existing `game_configs`.
- **Dependencies:** 5.4 (Banner & Scaling Editor) for HP/Gold tuning coverage. 2.4 (GameConfigs page) as the foundation to extend.

### 1.4 Relationship to 5.4
5.4 (Scaling & Difficulty) covers combat scaling, wave configuration, and difficulty curves. 5.5 covers everything else: drop rates, skill balance, economy, and the general-purpose config editor improvement. There is no overlap — HP/Gold scaling was explicitly merged into 5.4.

## 2. GameConfigs Category Reorganization

### 2.1 Concept
The existing GameConfigs page is reorganized from a flat table into a tabbed interface grouped by the existing `category` column. Each category tab displays its keys with type-aware input controls inferred from the current values.

### 2.2 Category Tabs
- [x] **2.2.1** Replace the flat GameConfigs table with a tab bar showing all distinct categories. Categories (19 after 5.4): `achievements`, `anti-cheat`, `artifacts`, `combat`, `discovery`, `donations`, `drops`, `economy`, `leaderboard`, `marketplace`, `marketplace_anomaly`, `progression`, `salvage`, `social`, `subscription`, `training`, `ui`, `upgrades`, `waves` (added by 5.4 migration 059).
- [x] **2.2.2** An "All" tab showing the current flat view (searchable, for power users).
- [x] **2.2.3** Category tabs show key count badges (e.g., "Combat (14)").
- [x] **2.2.4** Active search filters across all categories — matching keys are highlighted and their category tabs get visual indicators.

### 2.3 Type-Aware Inputs
- [x] **2.3.1** Infer input type from `value_json` content:
  - **Float 0.0–1.0**: Render as slider + number input (e.g., `crit_chance`, `rare_spawn_base_chance`)
  - **Positive integer**: Render as number input with step=1 (e.g., `monsters_per_zone`, `chat_buffer_size`)
  - **Positive float > 1.0**: Render as number input with step=0.01 (e.g., `hp_scaling_factor`, `upgrade_cost_scaling`)
  - **String**: Render as text input (e.g., Stripe price IDs)
  - **JSON array**: Render as JSON editor with syntax highlighting (e.g., `subscription_cumulative_milestones`)
  - **JSON object**: Render as JSON editor with syntax highlighting (e.g., `rarity_weight_book_1`)
  - **Boolean-like**: Render as toggle (e.g., `gift_counts_toward_loyalty`)
- [x] **2.3.2** Fallback: any value that doesn't match inference rules gets the existing raw JSON editor.
- [x] **2.3.3** `description` field displayed as inline help text below each input.
- [x] **2.3.4** `game_impact` field displayed as a tooltip on a "ℹ" icon next to the key name.
- [x] **2.3.5** "Modified" indicator: highlight keys changed from their default/seed value (compare against a stored baseline, or simply show "last updated" timestamp).

### 2.4 Enhanced Search
- [x] **2.4.1** Search bar filters by key name, description, and category.
- [x] **2.4.2** Search results show matching keys inline with their category context.
- [x] **2.4.3** "Jump to category" action from search results.

## 3. Drop Rate Manager (Specialized Tab)

### 3.1 Concept
A purpose-built panel grouping all drop-rate-related game_configs keys with visual distribution previews. All edits write directly to `game_configs` — no separate storage.

### 3.2 Drop Rate Groups
- [x] **3.2.1** **Artifact Drop Chances** — Group: `artifact_gen_drop_chance_scene`, `artifact_gen_drop_chance_boss`, `artifact_gen_drop_chance_mastery`. Display as labeled sliders (0.0–1.0) with percentage labels.
- [x] **3.2.2** **Artifact Rarity Weights** — Group: `artifact_rarity_weight_book_1`, `artifact_rarity_weight_book_2`, `artifact_rarity_weight_book_3`. Display each book's weights as a horizontal stacked bar showing the rarity distribution (Common → Cosmic). Editable weight values below the bar.
- [x] **3.2.3** **Dream Item Rarity Weights** — Group: `rarity_weight_book_1`, `rarity_weight_book_2`, `rarity_weight_book_3`. Same stacked bar display per book.
- [x] **3.2.4** **Gear Slot Weights** — Group: `gear_slot_weights_combat`, `gear_slot_weights_narrative`. Display as pie chart or proportional bar showing slot distribution.
- [x] **3.2.5** **Rare Spawn** — `rare_spawn_base_chance`. Slider with percentage display and contextual help: "At 0.5%, a player will see ~1 rare spawn every 200 waves."
- [x] **3.2.6** **Run Achievement Drops** — `run_achievement_config`. JSON editor with structured preview showing thresholds and drop chances.
- [x] **3.2.7** **Stat Multiplier** — `artifact_rarity_stat_multiplier`. Number input showing how rarity affects artifact stats.

### 3.3 Distribution Preview
- [x] **3.3.1** For each rarity weight group, show a computed preview: "Expected drops per 100 scenes at current rates" or similar contextual calculation.
- [x] **3.3.2** Preview updates reactively as admin adjusts values (before saving).
- [x] **3.3.3** Color-coded rarity labels matching the game's rarity tier colors (Common=gray, Uncommon=green, Rare=blue, Epic=purple, Legendary=orange, Cosmic=gold).

## 4. Skill Balance Viewer (Specialized Tab)

### 4.1 Concept
A read-only cross-reference table showing all skills alongside their effective combat values when combined with current game_configs coefficients. Edits to global coefficients happen inline; per-skill data is read-only (edited via ContentEditor).

### 4.2 Skill Balance Table
- [x] **4.2.1** Fetch all skills from `GET /api/admin/content/skills` (existing endpoint) and relevant game_configs keys.
- [x] **4.2.2** Table columns per skill:
  - **Skill Name** (from `skills.name` / `skills.display_name`)
  - **Category** (from `skills.category`)
  - **Class** (from `skills.class_id` → class name, or "Any")
  - **Base Cooldown** (from `skills.base_cooldown_seconds`)
  - **Base Cost** (from `skills.base_cost_gold`)
  - **Cost at Lv 5** — computed: `base_cost_gold × cost_scaling_factor^5`
  - **Cost at Lv 10** — computed: `base_cost_gold × cost_scaling_factor^10`
  - **Cost at Lv 25** — computed: `base_cost_gold × cost_scaling_factor^25`
  - **Effective Cooldown at Lv 10** — computed: `base_cooldown × (1 - min(cd_reduction_per_level × 10, max_cd_reduction))`
  - **Effective Cooldown at Lv 25** — computed: same formula at level 25
- [x] **4.2.3** Sortable by any column. Default sort by category then name.
- [x] **4.2.4** Filter by category and class.

### 4.3 Global Coefficients Panel
- [x] **4.3.1** Below the table, an editable panel showing the relevant game_configs keys:
  - `base_skill_unlock_cost`, `base_skill_level_upgrade_cost` (from `upgrades`)
  - `cd_reduction_per_level`, `max_cd_reduction` (from `upgrades`)
  - `int_power_coefficient`, `int_cooldown_coefficient` (from `combat`)
  - `gcd_ms` (from `combat`)
  - `upgrade_cost_scaling` (from `upgrades`)
- [x] **4.3.2** When a coefficient is changed (before save), the table above updates reactively to show the new computed values. Changed cells highlighted in yellow.
- [x] **4.3.3** "Save Changes" button writes modified game_configs values.
- [x] **4.3.4** "Reset to Current" button discards unsaved coefficient changes.

### 4.4 Cross-Link
- [x] **4.4.1** Each skill row has an "Edit in ContentEditor →" link that navigates to the ContentEditor Skills tab with that skill selected.

## 5. Economy Tuning Panel (Specialized Tab)

### 5.1 Concept
A purpose-built panel grouping economy-related game_configs with a reactive step-function visualization for the essence XP curve. All edits write directly to `game_configs`.

### 5.2 Essence XP Curve
- [x] **5.2.1** Display the 5 `idle_essence_xp_*` threshold keys as a reactive step-function chart:
  - X-axis: Essence % (0–100%)
  - Y-axis: XP Rate % (0–100%)
  - Steps at: `idle_essence_xp_floor_rate` (0% essence), `idle_essence_xp_critical_threshold`, `idle_essence_xp_low_threshold`, `idle_essence_xp_mid_threshold`, `idle_essence_xp_full_threshold`
  - Each step shows the XP rate multiplier at that essence level
- [x] **5.2.2** Editable input fields below the chart for each threshold and rate value. Chart updates reactively as values change.
- [x] **5.2.3** Contextual help: "At 0% Essence, XP is earned at [floor_rate]% rate. Training never fully stops."

### 5.3 Essence Economy
- [x] **5.3.1** Group: `idle_essence_drain_per_minute`, `idle_essence_capacity`, `idle_offline_cap_hours`. Labeled number inputs with descriptions.
- [x] **5.3.2** Group: `gold_to_essence_base_rate`, `gold_to_essence_growth_factor`. Number inputs with a contextual preview: "At Zone 1: [base_rate] gold per 1 Essence. At Zone 10: [computed] gold per 1 Essence."

### 5.4 Salvage Rates
- [x] **5.4.1** Display salvage-related keys as a rarity-to-essence table:

  | Rarity | Equipment Essence | Artifact Multiplier | Curated Bonus |
  |--------|-------------------|---------------------|---------------|
  | Common | [5___] | ×[2.0] | ×[1.15] |
  | Uncommon | [10__] | ×[2.0] | ×[1.15] |
  | Rare | [25__] | ×[2.0] | ×[1.15] |
  | Epic | [50__] | ×[2.0] | ×[1.15] |
  | Legendary | [100_] | ×[2.0] | ×[1.15] |

  Maps to: `salvage_equipment_common_essence` through `salvage_equipment_legendary_essence`, `salvage_artifact_multiplier`, `salvage_curated_bonus_multiplier`.
- [x] **5.4.2** Computed column: "Artifact Essence" = Equipment × Artifact Multiplier. "Curated Artifact Essence" = Artifact × Curated Bonus.

### 5.5 Subscription Boosts
- [x] **5.5.1** Group: `subscription_base_xp_boost`, `subscription_base_essence_boost`, `subscription_base_drop_boost`, `subscription_base_training_boost`, `subscription_base_stipend_shards`. Labeled sliders/inputs with percentage display (e.g., "+15% XP").
- [x] **5.5.2** Group: `subscription_streak_bonuses`, `subscription_cumulative_milestones`. JSON editors with structured preview.

### 5.6 Progression
- [x] **5.6.1** Group: `char_level_cap`, `char_level_xp_factor`, `char_xp_per_scene_base`, `idle_to_char_xp_ratio`, `lore_pool_coefficient`. Number inputs with contextual preview: "XP to reach Level 50: [computed]."

## 8. Design Decisions (Resolved)

| # | Decision | Resolution | Rationale |
|---|----------|------------|-----------|
| Q1 | Specialized vs. generic UI | Selective specialization — only where generic editor is inadequate | Drop rates need distribution previews; skills need cross-reference; economy needs curve viz. Others fine in improved generic editor. |
| Q2 | Drop Rate Manager scope | Global-only with better UI | Per-book rarity weights already exist as separate keys. Visual grouping + distribution previews sufficient. |
| Q3 | HP/Gold Scaler | Merged into 5.4 Scaling Preview | 5.4 already covers HP/Gold projections + difficulty presets. No duplication. |
| Q4 | Skill Balance depth | Cross-reference view — read-only skill data + editable global coefficients | Balance view shows combined effect; editing stays in ContentEditor. |
| Q5 | Economy Tuning scope | Grouped panel with reactive essence XP step-function visualization | Coupled threshold keys form a step function hard to reason about as raw numbers. |
| Q6 | GameConfigs improvement | Category tabs + type-inferred inputs (no schema changes) | Type inference from value_json covers 90% of cases without migration for 137 rows. |
| Q7 | Narrative Timing Editor | Skipped — single key stays in GameConfigs `ui` category | One key doesn't justify a dedicated panel. |
| Q8 | UI placement | Extend existing GameConfigs page with specialized tabs | One page for all tuning keeps the mental model simple. |
| Q9 | Skill balance columns | Core combat stats only — name, cooldown, cost at levels 1/5/10/25 | Balance view is for quick checks; detail editing in ContentEditor. |
| Q10 | Economy curve interactivity | Display-only reactive chart + editable inputs below | Draggable charts add significant complexity for infrequent use. |
