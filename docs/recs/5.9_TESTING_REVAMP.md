## Phase 0: Infrastructure

### 0.1 — Auth Bypass System (DB + .env Double-Gate)

A spoofing system that bypasses Firebase SSO for testing. **Two conditions must BOTH be true:**
1. `backend/.env` has `ALLOW_AUTH_BYPASS=true` (hardcoded, never set in production)
2. DB `server_configs` has `auth_bypass_enabled = true` (toggleable via Admin UI)

When both are active, the backend accepts a special header `X-Spoof-Player-Id: <player_id>` and treats that player as authenticated (skipping Firebase token verification).

#### Auth Bypass Flow
```
Frontend loads → GET /api/config/public → response includes { auth_bypass_available: true, bypass_player_id: 42 }
  → If available: skip Firebase, set X-Spoof-Player-Id header on all API calls
  → If not: normal Firebase SSO flow
```

#### Backend Logic (auth.py)
```
get_decoded_token(request):
  Gate 1: check os.getenv("ALLOW_AUTH_BYPASS") == "true" → if false, normal Firebase path
  Gate 2: check server_configs "auth_bypass_enabled" → if false, normal Firebase path
  Gate 3: check X-Spoof-Player-Id header → if present, look up player, return as authenticated
  Fallback: normal Firebase token verification
```

#### Safety
- Production `.env` NEVER has `ALLOW_AUTH_BYPASS=true`
- Even if DB toggle flipped in prod, `.env` gate blocks it
- Spoof requests logged to `activity_events` as `auth_bypass_used`

#### Files to Modify
- [backend/.env](backend/.env) — add `ALLOW_AUTH_BYPASS=false`
- [backend/.env.example](backend/.env.example) — add `ALLOW_AUTH_BYPASS=false` with comment
- [backend/auth.py](backend/auth.py) — spoof header check in `get_decoded_token()`
- [backend/routes/server_config.py](backend/routes/server_config.py) — ensure `auth_bypass_enabled` + `auth_bypass_player_id` config keys
- [admin/src/pages/ServerConfig.tsx](admin/src/pages/ServerConfig.tsx) — Auth Bypass toggle section
- [frontend/src/api.ts](frontend/src/api.ts) — attach spoof header when bypass active
- [frontend/src/App.tsx](frontend/src/App.tsx) — skip Firebase SSO popup when bypass active

### 0.2 — DB Dump/Restore Script

**New file:** `tools/db_dump_restore.py`

| Command | Action |
|---------|--------|
| `python tools/db_dump_restore.py dump` | `pg_dump` to `db/backups/<timestamp>.dump` |
| `python tools/db_dump_restore.py restore <file>` | `pg_restore --clean` from dump file |
| `python tools/db_dump_restore.py list` | List available backups |

- Connection string from `backend/.env` via `python-dotenv`
- Never prints/logs connection strings (per AGENTS.md mandate)
