# REC 2.5: Audio & Music Integration

This document defines the technical integration for the atmospheric audio system, procedural 8-bit asset generation, and administrative assignment tools for Elysium Rising.

---

## 1. Core Vision
The audio experience in ERP bridges the gap between a chiptune-inspired idle game and a deep narrative RPG. We employ **Programmatic 8-Bit Synthesis** to create a reactive soundscape that evolves with the player's progress through the Tower.

---

## 2. Atmospheric Music System

### 2.1 The Atmosphere Table (`atmospheres`)
Every Book, Chapter, and Scene is mapped to a **Base Atmosphere** extracted from the lore.
- **Attributes:**
  - `id`: Primary Key.
  - `name`: Lore-themed name (e.g., "Deep Tower", "The Substrate", "Neon Slums").
  - `description`: Narrative context for the mood.
- **States:** Each atmosphere supports 4 specific procedural tracks:
  1. **Exploring:** Upbeat/Ambient (Standard navigation).
  2. **Combat:** High-energy (Normal Waves).
  3. **Boss Battle:** Intense tension/Chromatic (Boss encounters).
  4. **Mystery:** Slow/Eerie (Lore reveals).

### 2.2 Dynamic Intensity & Evolution
Music is not static. The generator produces **Variations on a Theme**:
- **Layering:** As the player's Zone level increases, the engine layers in additional pulse-width channels, percussion, or arpeggios.
- **BPM Scaling:** Subtle tempo increases as tension builds in a scene.
- **Big Boss Overrides:** Named entities (e.g., "Yaldabaoth") can have unique, non-generic tracks assigned in the `entity_gameplay_data`.

### 2.3 Hierarchy & Inheritance
The `MusicManager` resolves the active track using a top-down lookup:
1. **Entity Level:** Is there a unique boss theme for the current target?
2. **Scene Level:** Does the current scene have an atmosphere override?
3. **Chapter Level:** Fallback to the chapter's base atmosphere.
4. **Book Level:** Final narrative fallback.
5. **Global Default:** Generic chiptune if all lookups fail (logs to `dev_content_audit`).

### 2.4 Audio Cross-fading
- Implement a **2.0s cross-fade** when transitioning between states (e.g., Exploring -> Combat).
- The `AudioPlayer` component must manage two concurrent audio elements to ensure seamless blending.

## 3. Procedural Sound Effects (SFX)

### 3.1 Event-Driven Mapping
The system triggers specific 8-bit SFX based on game events:
- **Interaction:** `on_click`, `on_menu_navigate`, `on_button_hover`.
- **Combat:** `on_hit`, `on_crit` (punchier/higher pitch), `on_enemy_death`, `on_skill_activate`.
- **Progression:** `on_level_up`, `on_item_drop` (rarity-scaled arpeggio), `on_achievement`.
- **Narrative:** `on_beat_reveal`, `on_chapter_complete`.

### 3.2 Spatial Audio Panning
- **Battle Banner Integration:** SFX are panned in the stereo field (left-to-right) based on the entity's X-coordinate in the PixiJS viewport.
- **Feedback:** Player-initiated skills originate from the left; enemy deaths originate from their specific position on the right.

## 4. Administrative Audio Editor (Admin Panel)

### 4.1 Atmosphere & Track Manager
A new tab in the Admin Panel allows admins to:
- Create and edit **Atmospheres**.
- Trigger the **8-Bit Music Generator** with specific mood parameters (BPM, Key, Intensity).
- **Audio Preview:** Built-in waveform visualizer and player to "test" tracks before assignment.
- **Batch Assignment:** Tool to apply an atmosphere to all scenes in a chapter or book.

### 4.2 SFX & Entity Mapping
- Interface to map `sfx_keys` to specific Skills and Entities.
- Ability to assign unique "Death Sounds" to Lore-important characters.

---

## 5. 8-Bit Asset Generator Pipeline

### 5.1 Music Generator (`tools/generate_8bit_music.py`)
Expansion of the existing synthesis tool:
- **Parameters:** Mood (BPM, Scale), Complexity (Layers), and Seed (for deterministic generation).
- **Output:** High-quality `.wav` files.

### 5.2 SFX Generator (`tools/generate_8bit_sfx.py`)
New procedural tool for chiptune sound effects:
- **Presets:** `jump`, `hit`, `explosion`, `powerup`, `blip`.
- **Randomization:** Subtle variations in pitch/decay to prevent "auditory fatigue" during high-frequency clicking.

### 5.3 Compression Utility (`tools/audio_compressor.py`)
- Batch conversion of `.wav` to `.mp3` using `ffmpeg`.
- Automated script to update all DB references from `.wav` to `.mp3`.

---

## 6. User Experience & Controls

### 6.1 Audio Settings UI
A unified modal for volume management:
- **Master Volume:** Global gain.
- **Music Volume:** Background music.
- **SFX Volume:** Tactical feedback.
- **Everything Mute:** Global toggle in the TopBar (persistent icon).
- **Persistence:** Settings saved to `player_settings` and `localStorage`.

---

## 7. Development Content Audit (`dev_content_audit`)
The audit system flags the following "Incomplete" audio states:
- **Missing Atmosphere:** Scene/Chapter has no atmosphere assigned.
- **Generic Fallback:** Using a generic track where lore-specific atmosphere is expected.
- **Missing Skill SFX:** Active skills triggered without an `sfx_key`.
- **Undefined Entity Sound:** Boss entities lacking unique death sounds.
- **Generic Stat Block:** Entities using fallback stats instead of lore-extracted data.
