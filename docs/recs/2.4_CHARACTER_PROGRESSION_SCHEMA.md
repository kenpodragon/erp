### 2.1 New Table: `idle_skill_stat_contributions`

Maps each idle skill to the stat(s) it contributes to, with a configurable coefficient. This is the extensibility hook — adding a new idle skill and its stat effect requires only a new row here.

```sql
CREATE TABLE IF NOT EXISTS idle_skill_stat_contributions (
    id              SERIAL PRIMARY KEY,
    idle_skill_id   INTEGER NOT NULL REFERENCES skills(id) ON DELETE CASCADE,
    stat_id         INTEGER NOT NULL REFERENCES stat_definitions(id) ON DELETE CASCADE,
    coefficient     NUMERIC(6,4) NOT NULL DEFAULT 0.5,
    description     TEXT,   -- e.g., "Attack level × 0.5 → Strength"
    created_at      TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at      TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    UNIQUE(idle_skill_id, stat_id)
);

CREATE TRIGGER update_idle_skill_stat_contributions_modtime
    BEFORE UPDATE ON idle_skill_stat_contributions
    FOR EACH ROW EXECUTE PROCEDURE update_updated_at_column();
```

**Column Descriptions:**

| Column | Type | Description |
|:---|:---|:---|
| `idle_skill_id` | INTEGER FK | The idle training skill (Attack, Magic, Lore, Precision, or any future skill) |
| `stat_id` | INTEGER FK | The stat that this skill contributes to |
| `coefficient` | NUMERIC(6,4) | `stat_bonus = floor(skill_level × coefficient)`. Default 0.5. |

> **Lore (special case):** Lore's contribution is class-dependent and does NOT map via this table. Instead, Lore distribution is handled by `class_stat_affinities.lore_weight`. Only Attack, Precision, and Magic have rows here.

### 2.2 New Table: `class_stat_affinities`

Per-class, per-stat configuration: base value, Lore distribution weight, and character level bonus rate. One row per (class, stat) pair.

```sql
CREATE TABLE IF NOT EXISTS class_stat_affinities (
    id                      SERIAL PRIMARY KEY,
    class_id                INTEGER NOT NULL REFERENCES character_classes(id) ON DELETE CASCADE,
    stat_id                 INTEGER NOT NULL REFERENCES stat_definitions(id) ON DELETE CASCADE,
    base_value              INTEGER NOT NULL DEFAULT 10,
    lore_weight             NUMERIC(5,4) NOT NULL DEFAULT 0.0,
    level_bonus_per_level   NUMERIC(5,4) NOT NULL DEFAULT 0.0,
    created_at              TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at              TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    UNIQUE(class_id, stat_id)
);

CREATE TRIGGER update_class_stat_affinities_modtime
    BEFORE UPDATE ON class_stat_affinities
    FOR EACH ROW EXECUTE PROCEDURE update_updated_at_column();
```

**Column Descriptions:**

| Column | Type | Description |
|:---|:---|:---|
| `base_value` | INTEGER | Starting stat value at character creation for this class-stat pair |
| `lore_weight` | NUMERIC(5,4) | Fraction of the Lore bonus pool assigned to this stat for this class. Must sum to 1.0 per class across all stats. |
| `level_bonus_per_level` | NUMERIC(5,4) | Flat bonus to this stat per character level. Primary stat typically 1.0, secondary 0.5 (floors at 0 for fractional levels). |

### 2.3 New Table: `character_stats`

Computed, cached per-character stat totals. Refreshed whenever a source changes (equip/unequip, idle level-up, character level-up). Avoids expensive joins on every request.

```sql
CREATE TABLE IF NOT EXISTS character_stats (
    id                  SERIAL PRIMARY KEY,
    character_id        INTEGER NOT NULL REFERENCES player_characters(id) ON DELETE CASCADE,
    stat_id             INTEGER NOT NULL REFERENCES stat_definitions(id) ON DELETE CASCADE,
    computed_total      INTEGER NOT NULL DEFAULT 0,
    last_computed_at    TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    UNIQUE(character_id, stat_id)
);
```

**Computation trigger events:**
- Idle skill level-up
- Character level-up
- Equip or unequip an item
- Admin override of character stat

> The backend `recalculate_character_stats(character_id)` service function reads `class_stat_affinities`, `idle_skill_stat_contributions`, `character_skill_levels`, `player_characters.level`, and `player_inventory` (equipped items) to rebuild all `character_stats` rows for the character.

### 2.4 Modify `player_characters`

Add Character XP tracking. The existing `level` column is retained — it now represents Character Level (driven by `character_xp`, not idle skill levels directly). The hardcoded `strength`, `agility`, `intelligence` columns are deprecated in favor of `character_stats` but retained for backward compatibility during migration.

```sql
ALTER TABLE player_characters
    ADD COLUMN IF NOT EXISTS character_xp BIGINT NOT NULL DEFAULT 0;

-- Deprecation note: strength, agility, intelligence columns are no longer the
-- authoritative source. The character_stats table is authoritative.
-- These columns will be removed in a future cleanup migration once all read paths
-- have been updated to use character_stats.
COMMENT ON COLUMN player_characters.strength     IS 'DEPRECATED in 2.4. Use character_stats table.';
COMMENT ON COLUMN player_characters.agility      IS 'DEPRECATED in 2.4. Use character_stats table.';
COMMENT ON COLUMN player_characters.intelligence IS 'DEPRECATED in 2.4. Use character_stats table.';
```

### 2.5 Modify `chapters` and `books`

Add level requirement gates for content access.

```sql
ALTER TABLE chapters
    ADD COLUMN IF NOT EXISTS recommended_level INTEGER DEFAULT NULL,
    ADD COLUMN IF NOT EXISTS min_level         INTEGER DEFAULT NULL;

ALTER TABLE books
    ADD COLUMN IF NOT EXISTS recommended_level INTEGER DEFAULT NULL,
    ADD COLUMN IF NOT EXISTS min_level         INTEGER DEFAULT NULL;
```

**Behavior:**
- `recommended_level`: Advisory only. Shown in UI as a suggestion before entry; does not block the player.
- `min_level`: Hard gate. The backend rejects a story session start request if `character.level < chapter.min_level`.
- NULL values on both fields = no gate (applies to all existing chapters on migration).

### 2.8 New Table: `player_scene_records`

Per-player, per-scene personal bests. Upserted at the end of each Story Mode run. Used for "High Tide" achievement evaluation and future leaderboard features.

```sql
CREATE TABLE IF NOT EXISTS player_scene_records (
    id                      SERIAL PRIMARY KEY,
    player_id               INTEGER NOT NULL REFERENCES players(id) ON DELETE CASCADE,
    scene_id                INTEGER NOT NULL REFERENCES scenes(id) ON DELETE CASCADE,
    best_wave               INTEGER NOT NULL DEFAULT 0,
    best_time_seconds       INTEGER DEFAULT NULL,   -- fastest completion time (NULL if never completed)
    total_enemies_killed    BIGINT NOT NULL DEFAULT 0,
    total_runs              INTEGER NOT NULL DEFAULT 0,
    first_completed_at      TIMESTAMP WITH TIME ZONE DEFAULT NULL,
    updated_at              TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    UNIQUE(player_id, scene_id)
);

CREATE TRIGGER update_player_scene_records_modtime
    BEFORE UPDATE ON player_scene_records
    FOR EACH ROW EXECUTE PROCEDURE update_updated_at_column();

CREATE INDEX IF NOT EXISTS idx_player_scene_records_player
    ON player_scene_records(player_id);
```

**Column Descriptions:**

| Column | Type | Description |
|:---|:---|:---|
| `best_wave` | INTEGER | Highest wave ever reached in this scene. Updated via `GREATEST(best_wave, new_wave)`. |
| `best_time_seconds` | INTEGER | Fastest completion time. NULL until first completion. Updated via `LEAST(best_time, new_time)`. |
| `total_enemies_killed` | BIGINT | Cumulative enemies killed across all runs of this scene. |
| `total_runs` | INTEGER | Number of runs started for this scene. |

### 3.3 Seed `class_stat_affinities`

```sql
-- ═══════════════════════════════════════════════════════
-- DRIFTER: Primary=STR, Secondary=AGI
-- Lore: 60% to STR, 40% to AGI
-- Level bonus: +1.0 STR/level, +0.5 AGI/level (≈ +1 every 2 levels)
-- ═══════════════════════════════════════════════════════
INSERT INTO class_stat_affinities (class_id, stat_id, base_value, lore_weight, level_bonus_per_level)
SELECT cc.id, sd.id, val.base, val.lore_w, val.lvl_bonus
FROM character_classes cc,
     stat_definitions sd,
     (VALUES
         ('strength',     15, 0.60, 1.0),
         ('agility',      10, 0.40, 0.5),
         ('intelligence',  5, 0.00, 0.0)
     ) AS val(stat_name, base, lore_w, lvl_bonus)
WHERE cc.name = 'Drifter' AND sd.name = val.stat_name
ON CONFLICT (class_id, stat_id) DO UPDATE
    SET base_value = EXCLUDED.base_value,
        lore_weight = EXCLUDED.lore_weight,
        level_bonus_per_level = EXCLUDED.level_bonus_per_level;

-- ═══════════════════════════════════════════════════════
-- ENGINEER: Primary=AGI, Secondary=STR
-- Lore: 60% to AGI, 40% to STR
-- Level bonus: +1.0 AGI/level, +0.5 STR/level
-- ═══════════════════════════════════════════════════════
INSERT INTO class_stat_affinities (class_id, stat_id, base_value, lore_weight, level_bonus_per_level)
SELECT cc.id, sd.id, val.base, val.lore_w, val.lvl_bonus
FROM character_classes cc,
     stat_definitions sd,
     (VALUES
         ('strength',      5, 0.40, 0.5),
         ('agility',      15, 0.60, 1.0),
         ('intelligence', 10, 0.00, 0.0)
     ) AS val(stat_name, base, lore_w, lvl_bonus)
WHERE cc.name = 'Engineer' AND sd.name = val.stat_name

        lore_weight = EXCLUDED.lore_weight,
```

### 3.5 Seed `chapters.recommended_level`

```sql
-- Book 1 chapters: level 0 → 18 (progressive)
-- Assumes chapters are ordered by sort_order within each book
-- Exact values tuned to: start=0, midpoint=10, end≈18
UPDATE chapters SET recommended_level = sub.rec_level
FROM (
    SELECT c.id,
           ROUND(
               18.0 * (ROW_NUMBER() OVER (PARTITION BY c.book_id ORDER BY c.sort_order) - 1)
               / NULLIF(COUNT(*) OVER (PARTITION BY c.book_id) - 1, 0)
           )::INTEGER AS rec_level
    FROM chapters c
    JOIN books b ON b.id = c.book_id
    WHERE b.book_number = 1
) sub
WHERE chapters.id = sub.id AND chapters.recommended_level IS NULL;

-- Book 2 chapters: level 20 → 55
UPDATE chapters SET recommended_level = sub.rec_level
FROM (
    SELECT c.id,
           (20 + ROUND(
               35.0 * (ROW_NUMBER() OVER (PARTITION BY c.book_id ORDER BY c.sort_order) - 1)
               / NULLIF(COUNT(*) OVER (PARTITION BY c.book_id) - 1, 0)
           ))::INTEGER AS rec_level
    FROM chapters c
    JOIN books b ON b.id = c.book_id
    WHERE b.book_number = 2
) sub
WHERE chapters.id = sub.id AND chapters.recommended_level IS NULL;

-- Book 3 chapters: level 60 → 90 (flattened curve)
UPDATE chapters SET recommended_level = sub.rec_level
FROM (
    SELECT c.id,
           (60 + ROUND(
               30.0 * (ROW_NUMBER() OVER (PARTITION BY c.book_id ORDER BY c.sort_order) - 1)
               / NULLIF(COUNT(*) OVER (PARTITION BY c.book_id) - 1, 0)
           ))::INTEGER AS rec_level
    FROM chapters c
    JOIN books b ON b.id = c.book_id
    WHERE b.book_number = 3
) sub
WHERE chapters.id = sub.id AND chapters.recommended_level IS NULL;

-- Books themselves get start-of-book recommended_level
UPDATE books SET recommended_level = 0  WHERE book_number = 1 AND recommended_level IS NULL;
UPDATE books SET recommended_level = 20 WHERE book_number = 2 AND recommended_level IS NULL;
UPDATE books SET recommended_level = 60 WHERE book_number = 3 AND recommended_level IS NULL;
```

### 4.1 New Table: `skill_prerequisites`

Unified prerequisite tree. One row per prerequisite condition on a skill. Multiple rows = AND-gated (all must be satisfied).

```sql
CREATE TABLE IF NOT EXISTS skill_prerequisites (
    id                  SERIAL PRIMARY KEY,
    skill_id            INTEGER NOT NULL REFERENCES skills(id) ON DELETE CASCADE,
    prerequisite_type   VARCHAR(30) NOT NULL
                            CHECK (prerequisite_type IN (
                                'idle_skill_level',   -- ref_id = skills.id (an idle skill)
                                'active_skill_level', -- ref_id = skills.id (an active/hotbar skill)
                                'stat_value',         -- ref_id = stat_definitions.id
                                'character_level',    -- ref_id = NULL (uses min_value directly)
                                'scene_cleared'       -- ref_id = scenes.id
                            )),
    ref_id              INTEGER DEFAULT NULL,
    -- For idle_skill_level / active_skill_level: FK to skills.id
    -- For stat_value:                            FK to stat_definitions.id
    -- For scene_cleared:                         FK to scenes.id
    -- For character_level:                       NULL (threshold in min_value)
    min_value           INTEGER NOT NULL DEFAULT 1,
    -- For skill_level types: minimum level required
    -- For stat_value:        minimum computed stat total
    -- For character_level:   minimum character level
    -- For scene_cleared:     always 1 (boolean: scene must be cleared)
    display_hint        TEXT DEFAULT NULL,
    -- Optional UI-facing hint: "Requires Magic Level 10" (auto-generated if NULL)
    created_at          TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_skill_prerequisites_skill_id
    ON skill_prerequisites(skill_id);
```

> **Note:** `ref_id` is not a formal FK constraint because it points to different tables depending on `prerequisite_type`. Integrity is enforced at the application layer. A partial index or a polymorphic FK pattern may be added in a future cleanup migration.

### 4.2 Modify `skills`

Add Level 0 XP requirement and class-exclusivity support.

```sql
ALTER TABLE skills
    ADD COLUMN IF NOT EXISTS level_0_xp_requirement INTEGER NOT NULL DEFAULT 0,
    ADD COLUMN IF NOT EXISTS class_id               INTEGER REFERENCES character_classes(id) ON DELETE SET NULL,
    ADD COLUMN IF NOT EXISTS is_class_exclusive      BOOLEAN NOT NULL DEFAULT FALSE,
    ADD COLUMN IF NOT EXISTS idle_level_scaling      JSONB   DEFAULT NULL,
    -- Maps idle level breakpoints to base power values for active skills.
    -- e.g., {"base_clicks_per_sec": {"1": 1, "10": 2, "25": 3, "50": 5, "99": 10}}
    -- NULL for idle-only skills (Attack, Magic, Lore, Precision).
    ADD COLUMN IF NOT EXISTS effect_type             VARCHAR(50) DEFAULT NULL;
    -- References benefit_effect_data.effect_key. Used by frontend handler map.
    -- e.g., 'click_burst', 'damage_multiplier', 'aoe_burst', 'crit_boost'
```

**Column Descriptions:**

| Column | Type | Description |
|:---|:---|:---|
| `level_0_xp_requirement` | INTEGER | XP needed to advance from Level 0 → Level 1. `0` = skill uses standard curve (no Level 0 state; applies to Attack). Any positive value enables the Level 0 locked state. |
| `class_id` | INTEGER FK | If set, this skill is visible only to characters of this class. NULL = universal skill. |
| `is_class_exclusive` | BOOLEAN | Redundant but explicit flag for quick filtering. Must be TRUE if `class_id` is set. |
| `idle_level_scaling` | JSONB | For active skills: maps idle level breakpoints → base power values. Frontend interpolates between breakpoints. NULL for idle-only skills. |
| `effect_type` | VARCHAR(50) | References `benefit_effect_data.effect_key`. Frontend handler map uses this to determine skill behavior. |

```sql
ALTER TABLE character_skill_levels
```

**Column Description:**

| Column | Type | Description |
|:---|:---|:---|
| `max_session_level` | INTEGER | The highest level this skill has ever been purchased to across all Story Mode sessions. Updated at session end if current session level > stored max. Used for `active_skill_level` prerequisite checks. |

### 6.8 Modify `player_inventory`

Add slot capacity enforcement via a trigger. The hard cap is 10 stored (non-equipped) items + 3 equipped slots per character.

```sql
-- Remove the quantity column from consideration for Dream Items (always 1 per row)
-- No structural change needed — quantity stays, but Dream Item rows always have quantity = 1.

-- Enforce max 10 non-equipped items per character via trigger
CREATE OR REPLACE FUNCTION enforce_inventory_slot_cap()
RETURNS TRIGGER AS $$
DECLARE
    stored_count INTEGER;
BEGIN
    -- Only check if this is a non-equipped item being inserted
    IF NEW.is_equipped = FALSE OR NEW.is_equipped IS NULL THEN
        SELECT COUNT(*) INTO stored_count
        FROM player_inventory
        WHERE character_id = NEW.character_id
          AND (is_equipped = FALSE OR is_equipped IS NULL);

        IF stored_count >= 10 THEN
            RAISE EXCEPTION 'Inventory full: maximum 10 stored items per character. Delete an item to make room.'
                USING ERRCODE = 'check_violation';
        END IF;
    END IF;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_enforce_inventory_slot_cap
    BEFORE INSERT ON player_inventory
    FOR EACH ROW EXECUTE FUNCTION enforce_inventory_slot_cap();
```

## 9. Backend Logic Notes

### 9.1 Stat Recalculation Service

```python
def recalculate_character_stats(db, character_id: int) -> None:
    """
    Rebuilds all character_stats rows for a character from all sources.
    Call this after: idle level-up, character level-up, equip/unequip, admin override.
    """
    character = db.get(PlayerCharacter, character_id)
    class_affinities = db.exec(
        select(ClassStatAffinity).where(ClassStatAffinity.class_id == character.class_id)
    ).all()

    idle_contributions = db.exec(select(IdleSkillStatContribution)).all()
    skill_levels = {
        row.skill_id: row.level
        for row in db.exec(
            select(CharacterSkillLevel)
            .where(CharacterSkillLevel.character_id == character_id)
        ).all()
    }

    equipped_items = db.exec(
        select(PlayerInventory)
        .join(InventoryItem)
        .where(PlayerInventory.character_id == character_id,
               PlayerInventory.is_equipped == True)
    ).all()

    stat_totals = {}

    for affinity in class_affinities:
        stat_id = affinity.stat_id
        total = affinity.base_value

        # Idle training contributions (Attack→STR, Precision→AGI, Magic→INT)
        for contrib in idle_contributions:
            if contrib.stat_id == stat_id:
                level = skill_levels.get(contrib.idle_skill_id, 0)
                total += int(level * float(contrib.coefficient))

        # Lore distribution (class-specific via lore_weight)
        lore_skill = get_skill_by_name(db, 'Lore')
        lore_level = skill_levels.get(lore_skill.id, 0)
        lore_pool_coeff = get_config(db, 'lore_pool_coefficient', 0.6)
        lore_pool = int(lore_level * lore_pool_coeff)
        total += int(lore_pool * float(affinity.lore_weight))

        # Character level bonus
        char_level = character.level
        total += int(char_level * float(affinity.level_bonus_per_level))

        # Equipment bonuses
        for inv_row in equipped_items:
            item_stats = inv_row.item.base_stats or {}
            stat_name = get_stat_name(db, stat_id)
            total += item_stats.get(stat_name, 0)

        stat_totals[stat_id] = max(0, total)

    # Upsert character_stats
    for stat_id, total in stat_totals.items():
        existing = db.exec(
            select(CharacterStat)
            .where(CharacterStat.character_id == character_id,
                   CharacterStat.stat_id == stat_id)
        ).first()
        if existing:
            existing.computed_total = total
            existing.last_computed_at = datetime.utcnow()
        else:
            db.add(CharacterStat(character_id=character_id, stat_id=stat_id,
                                  computed_total=total))
    db.commit()
```

### 9.2 Prerequisite Check Service

```python
def check_skill_prerequisites(db, character_id: int, skill_id: int) -> tuple[bool, list[str]]:
    """
    Returns (all_met: bool, unmet_hints: list[str]).
    """
    prereqs = db.exec(
        select(SkillPrerequisite).where(SkillPrerequisite.skill_id == skill_id)
    ).all()

    unmet = []
    for prereq in prereqs:
        met = False
        if prereq.prerequisite_type == 'idle_skill_level':
            row = get_skill_level(db, character_id, prereq.ref_id)
            met = (row.level if row else 0) >= prereq.min_value

        elif prereq.prerequisite_type == 'active_skill_level':
            row = get_skill_level(db, character_id, prereq.ref_id)
            met = (row.max_session_level if row else 0) >= prereq.min_value

        elif prereq.prerequisite_type == 'stat_value':
            stat_row = get_character_stat(db, character_id, prereq.ref_id)
            met = (stat_row.computed_total if stat_row else 0) >= prereq.min_value

        elif prereq.prerequisite_type == 'character_level':
            char = db.get(PlayerCharacter, character_id)
            met = char.level >= prereq.min_value

        elif prereq.prerequisite_type == 'scene_cleared':
            met = is_scene_cleared(db, character_id, prereq.ref_id)

        if not met:
            unmet.append(prereq.display_hint or f"Requires {prereq.prerequisite_type} {prereq.min_value}")

    return len(unmet) == 0, unmet
```

### 9.3 Character XP Accrual

```python
def award_character_xp(db, character_id: int, xp_amount: int) -> bool:
    """
    Awards Character XP and applies level-ups. Returns True if level-up occurred.
    """
    char = db.get(PlayerCharacter, character_id)
    char.character_xp += xp_amount

    leveled_up = False
    k = int(get_config(db, 'char_level_xp_factor', 1000))
    cap = int(get_config(db, 'char_level_cap', 99))

    while char.level < cap:
        xp_to_next = k * ((char.level + 1) ** 2)
        if char.character_xp >= xp_to_next:
            char.level += 1
            leveled_up = True
        else:
            break

    if leveled_up:
        recalculate_character_stats(db, character_id)

    db.commit()
    return leveled_up
```
