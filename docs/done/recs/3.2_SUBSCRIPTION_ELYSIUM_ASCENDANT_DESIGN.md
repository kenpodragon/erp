### 1.2 Key Design Decisions

#### No Cron Jobs — Fully Lazy/On-Access
All subscription state transitions that don't originate from Stripe webhooks are evaluated **lazily on access**:

| Operation | Trigger |
|:---|:---|
| **Stipend crediting** (annual subs) | `GET /api/subscriptions/status` or any endpoint calling `get_subscriber_multipliers()` |
| **Grace period expiration** | `GET /api/subscriptions/status` or any endpoint calling `_resolve_subscription_status()` |
| **Loyalty milestone checks** | On `invoice.paid` webhook (renewal) and on status access |

This means:
- No background scheduler or cron infrastructure needed.
- A player who doesn't log in during a grace period will have their status resolved on next access.
- Annual stipend credits may be delayed until the player next accesses their subscription status — this is acceptable since shards appear on their next interaction.

#### Separate `player_subscriptions` Table (Append-Only)
Subscription state lives in its own table, not on `players`. Each subscription period gets its **own row** — when a player re-subscribes after a lapse, a new row is created (the old row stays with `status = 'expired'` for historical reference). The `players` table gets only:
- `is_ascendant BOOLEAN` — fast-lookup flag, kept in sync by the subscription service.
- `cumulative_subscription_months INT` — lifetime total, never decremented (except on refund).

The **active subscription** is always the row with the latest `created_at` and `status IN ('active', 'past_due', 'canceling')`. Queries for current state use this filter. Historical queries can scan all rows for a player.

**Why append-only:**
- Full audit trail of every subscription period (start, end, plan, source).
- No data loss on re-subscribe — the old period's streak, plan, dates are preserved.
- Simplifies refund logic — each refund targets a specific subscription row.
- `continuous_streak` lives on the active row; `cumulative_subscription_months` on the player (survives row transitions).

### 1.3 Route: `POST /api/subscriptions/create`

**Auth:** Required (Firebase JWT)
**Rate Limit:** 3 req/player/min

```
Request:
{
  "plan_key": "ascendant_monthly" | "ascendant_annual"
}

Response (200):
{
  "checkout_url": "https://checkout.stripe.com/...",
  "session_id": "cs_test_..."
}

Errors:
  400 — Already subscribed (active/past_due/canceling)
  400 — Invalid plan_key
  403 — Account has active dispute
  429 — Rate limited
```

**Flow:**
1. Check `player.account_flag` — if `'dispute'`, return 403.
2. Check for existing `PlayerSubscription` with `status IN ('active', 'past_due', 'canceling')` → 400.
3. Look up Stripe Price ID from `game_configs` by `plan_key`:
   - `ascendant_monthly` → `game_configs['stripe_ascendant_monthly_price_id']`
   - `ascendant_annual` → `game_configs['stripe_ascendant_annual_price_id']`
4. Call `get_or_create_stripe_customer()` (reuse from 3.1).
5. Create Stripe Checkout Session:
   - `mode = "subscription"`
   - `customer = stripe_customer_id`
   - `line_items = [{ price: price_id, quantity: 1 }]`
   - `metadata = { player_id, plan_key }`
   - `success_url = f"{FRONTEND_URL}/subscription?session_id={CHECKOUT_SESSION_ID}"`
   - `cancel_url = f"{FRONTEND_URL}/subscription"`
6. Return checkout URL.

## 2. Subscription Service

### 2.1 Subscription Lifecycle — `subscription_service.py`

```python
# backend/services/subscription_service.py

def activate_subscription(player_id: int, stripe_sub_id: str, plan_key: str,
                          price_id: str, current_period_end: datetime,
                          session: Session) -> PlayerSubscription:
    """Called by checkout.session.completed webhook. Always creates a NEW row (append-only)."""
    # Ensure any prior active subscription is marked expired (defensive)
    prior = _get_active_subscription(player_id, session)
    if prior and prior.stripe_subscription_id != stripe_sub_id:
        prior.status = "expired"
        session.add(prior)

    # Check for idempotency — same Stripe sub ID already tracked
    existing = session.exec(
        select(PlayerSubscription).where(
            PlayerSubscription.stripe_subscription_id == stripe_sub_id
        )
    ).first()
    if existing:
        return existing  # Already activated (webhook replay)

    # Create new subscription row
    sub = PlayerSubscription(
        player_id=player_id,
        stripe_subscription_id=stripe_sub_id,
        stripe_price_id=price_id,
        plan_key=plan_key,
        status="active",
        source="stripe",
        current_period_start=datetime.now(timezone.utc),
        current_period_end=current_period_end,
        subscription_start_date=datetime.now(timezone.utc),
        cancel_at_period_end=False,
        continuous_streak=0,  # Incremented on first invoice.paid
    )
    session.add(sub)

    # Set fast-lookup flag
    session.execute(
        text("UPDATE players SET is_ascendant = TRUE WHERE id = :pid"),
        {"pid": player_id},
    )

    # NOTE: Initial stipend is NOT credited here. Stipend is only credited
    # when invoice.paid fires (which Stripe sends for the first payment too).
    # This ensures payment is confirmed before shards are granted.

    session.flush()
    return sub


def _get_active_subscription(player_id: int, session: Session) -> PlayerSubscription | None:
    """Get the current active subscription row for a player (if any)."""
    return session.exec(
        select(PlayerSubscription).where(
            PlayerSubscription.player_id == player_id,
            PlayerSubscription.status.in_(["active", "past_due", "canceling"]),
        ).order_by(PlayerSubscription.created_at.desc())
    ).first()


def renew_subscription(sub: PlayerSubscription, new_period_end: datetime,
                       invoice_id: str, session: Session) -> None:
    """Called by invoice.paid webhook. Extends period, increments counters, credits stipend."""
    # Idempotency: check if this invoice was already processed
    existing_stipend = session.exec(
        select(SubscriptionStipendLog).where(
            SubscriptionStipendLog.stripe_invoice_id == invoice_id
        )
    ).first()
    if existing_stipend:
        return  # Already processed

    sub.current_period_end = new_period_end
    sub.status = "active"
    sub.grace_period_start = None
    sub.grace_deadline = None
    sub.continuous_streak += 1
    session.add(sub)

    # Increment cumulative months on the player record (persists across sub rows)
    session.execute(
        text("UPDATE players SET cumulative_subscription_months = "
             "cumulative_subscription_months + 1 WHERE id = :pid"),
        {"pid": sub.player_id},
    )

    # Credit stipend
    _credit_stipend(sub, session, invoice_id=invoice_id)

    # Check loyalty milestones (reads cumulative from player record)
    _check_loyalty_milestones(sub, session)


def start_grace_period(sub: PlayerSubscription, session: Session) -> None:
    """Called by invoice.payment_failed webhook."""
    if sub.grace_period_start is not None:
        return  # Grace already started (idempotent)

    sub.status = "past_due"
    sub.grace_period_start = datetime.now(timezone.utc)
    sub.grace_deadline = calculate_grace_deadline(sub.grace_period_start)
    session.add(sub)


def expire_subscription(sub: PlayerSubscription, session: Session) -> None:
    """Revoke all benefits. Called by webhook or lazy evaluation."""
    sub.status = "expired"
    sub.continuous_streak = 0
    sub.grace_period_start = None
    sub.grace_deadline = None
    session.add(sub)

    # Revoke fast-lookup flag
    session.execute(
        text("UPDATE players SET is_ascendant = FALSE WHERE id = :pid"),
        {"pid": sub.player_id},
    )

    # Unequip "the Ascendant" title if equipped
    _unequip_ascendant_title(sub.player_id, session)


def refund_subscription(sub: PlayerSubscription, session: Session,
                        refund_all: bool = True) -> None:
    """Called by charge.refunded webhook for subscription charges.

    For full refund (refund_all=True): claws back ALL stipends credited during
    this subscription row's lifetime.
    For partial refund: caller should calculate proportional clawback externally.
    """
    # Calculate stipend clawback — ALL stipends for this subscription row
    stipend_logs = session.exec(
        select(SubscriptionStipendLog).where(
            SubscriptionStipendLog.subscription_id == sub.id,
        )
    ).all()

    total_clawback = sum(log.shards_credited for log in stipend_logs)
    if total_clawback > 0:
        debit_shards(
            player_id=sub.player_id,
            amount=total_clawback,
            source_type="subscription_refund",
            source_id=sub.id,
            description=f"Subscription refund — stipend clawback ({total_clawback} shards)",
            session=session,
        )

    # Decrement cumulative months on the player record for refunded period
    session.execute(
        text("UPDATE players SET cumulative_subscription_months = "
             "GREATEST(cumulative_subscription_months - 1, 0) WHERE id = :pid"),
        {"pid": sub.player_id},
    )

    # Expire
    expire_subscription(sub, session)
```

### 2.2 Business-Day Grace Period Calculator

```python
from datetime import date, timedelta

# US Federal Holidays — observed dates (shifted for weekends)
US_FEDERAL_HOLIDAYS = {
    # These are generated per-year. We precompute for the current + next year.
    # MLK Day: 3rd Monday of January
    # Presidents' Day: 3rd Monday of February
    # Memorial Day: Last Monday of May
    # Juneteenth: June 19 (observed)
    # Independence Day: July 4 (observed)
    # Labor Day: 1st Monday of September
    # Columbus Day: 2nd Monday of October
    # Veterans Day: November 11 (observed)
    # Thanksgiving: 4th Thursday of November
    # Christmas: December 25 (observed)
    # New Year's Day: January 1 (observed)
}

def _get_holidays_for_year(year: int) -> set[date]:
    """Compute observed US federal holiday dates for a given year."""
    holidays = set()

    # New Year's Day
    holidays.add(_observed(date(year, 1, 1)))
    # MLK Day: 3rd Monday of January
    holidays.add(_nth_weekday(year, 1, 0, 3))  # Monday=0
    # Presidents' Day: 3rd Monday of February
    holidays.add(_nth_weekday(year, 2, 0, 3))
    # Memorial Day: Last Monday of May
    holidays.add(_last_weekday(year, 5, 0))
    # Juneteenth
    holidays.add(_observed(date(year, 6, 19)))
    # Independence Day
    holidays.add(_observed(date(year, 7, 4)))
    # Labor Day: 1st Monday of September
    holidays.add(_nth_weekday(year, 9, 0, 1))
    # Columbus Day: 2nd Monday of October
    holidays.add(_nth_weekday(year, 10, 0, 2))
    # Veterans Day
    holidays.add(_observed(date(year, 11, 11)))
    # Thanksgiving: 4th Thursday of November
    holidays.add(_nth_weekday(year, 11, 3, 4))  # Thursday=3
    # Christmas
    holidays.add(_observed(date(year, 12, 25)))

    return holidays

def _observed(d: date) -> date:
    """If a holiday falls on Saturday, observe Friday. If Sunday, observe Monday."""
    if d.weekday() == 5:  # Saturday
        return d - timedelta(days=1)
    elif d.weekday() == 6:  # Sunday
        return d + timedelta(days=1)
    return d

def _nth_weekday(year: int, month: int, weekday: int, n: int) -> date:
    """Find the nth occurrence of a weekday in a month."""
    d = date(year, month, 1)
    count = 0
    while True:
        if d.weekday() == weekday:
            count += 1
            if count == n:
                return d
        d += timedelta(days=1)

def _last_weekday(year: int, month: int, weekday: int) -> date:
    """Find the last occurrence of a weekday in a month."""
    if month == 12:
        d = date(year + 1, 1, 1) - timedelta(days=1)
    else:
        d = date(year, month + 1, 1) - timedelta(days=1)
    while d.weekday() != weekday:
        d -= timedelta(days=1)
    return d

def _is_business_day(d: date, custom_holidays: list[str] | None = None) -> bool:
    """Check if a date is a US business day."""
    if d.weekday() >= 5:  # Saturday or Sunday
        return False
    holidays = _get_holidays_for_year(d.year)
    if d in holidays:
        return False
    if custom_holidays:
        for h in custom_holidays:
            if date.fromisoformat(h) == d:
                return False
    return True

def _next_business_day(d: date, custom_holidays: list[str] | None = None) -> date:
    """Find the next business day strictly after the given date."""
    candidate = d + timedelta(days=1)
    while not _is_business_day(candidate, custom_holidays):
        candidate += timedelta(days=1)
    return candidate

def calculate_grace_deadline(failure_time: datetime,
                             custom_holidays: list[str] | None = None) -> datetime:
    """
    Grace period = end of next US business day after the failure date (UTC).

    Returns a datetime at 23:59:59 UTC on the next business day.
    """
    failure_date = failure_time.date()  # UTC date
    next_bday = _next_business_day(failure_date, custom_holidays)
    return datetime(next_bday.year, next_bday.month, next_bday.day,
                    23, 59, 59, tzinfo=timezone.utc)
```

### 2.3 Lazy Subscription Status Resolution

```python
def resolve_subscription_status(player_id: int, session: Session) -> PlayerSubscription | None:
    """
    Load and lazily resolve subscription status.
    Called by GET /api/subscriptions/status and get_subscriber_multipliers().

    Uses _get_active_subscription() to find the latest active/past_due/canceling row.
    If none found, returns the most recent expired row (for cumulative_months display).

    Side effects:
    - Expires past_due subscriptions whose grace period has elapsed.
    - Credits stipends for annual subscribers whose anniversary has passed.
    """
    sub = _get_active_subscription(player_id, session)

    if sub is None:
        # Return latest expired row for cumulative_months context
        sub = session.exec(
            select(PlayerSubscription).where(
                PlayerSubscription.player_id == player_id,
            ).order_by(PlayerSubscription.created_at.desc())
        ).first()
        return sub  # May still be None if never subscribed

    now = datetime.now(timezone.utc)

    # 1. Grace period expiration check
    if sub.status == "past_due" and sub.grace_deadline and now > sub.grace_deadline:
        expire_subscription(sub, session)
        session.commit()
        return sub

    # 2. End-of-period expiration for canceling subs
    if sub.status == "canceling" and sub.current_period_end and now > sub.current_period_end:
        expire_subscription(sub, session)
        session.commit()
        return sub

    # 3. Stipend credit check (annual subscribers)
    if sub.status == "active" and sub.plan_key == "ascendant_annual":
        _credit_stipend_if_due(sub, session)

    return sub
```

### 2.4 Stipend Crediting (Lazy, On-Access)

```python
def _credit_stipend_if_due(sub: PlayerSubscription, session: Session) -> bool:
    """
    For annual subscribers: check if a monthly anniversary stipend is due.
    Uses subscription_stipend_log for idempotency.

    Returns True if a stipend was credited.
    """
    if sub.status != "active":
        return False

    now = datetime.now(timezone.utc)
    sub_start = sub.subscription_start_date or sub.current_period_start

    # Calculate the monthly anniversary dates since subscription start
    # and check which ones haven't been credited yet
    months_elapsed = _months_between(sub_start, now)

    for month_offset in range(1, months_elapsed + 1):
        anniversary_date = _add_months(sub_start, month_offset)
        if anniversary_date > now:
            break

        # Check if already credited for this period
        period_key = anniversary_date.strftime("%Y-%m")
        existing = session.exec(
            select(SubscriptionStipendLog).where(
                SubscriptionStipendLog.subscription_id == sub.id,
                SubscriptionStipendLog.period_key == period_key,
            )
        ).first()

        if existing:
            continue

        # Credit the stipend
        _credit_stipend(sub, session, period_key=period_key)

    return True


def _credit_stipend(sub: PlayerSubscription, session: Session,
                    invoice_id: str | None = None,
                    period_key: str | None = None) -> None:
    """Credit monthly shard stipend for a subscriber."""
    # Calculate stipend amount (base + streak bonus)
    stipend = _calculate_stipend_amount(sub, session)

    # Credit shards
    meta = session.get(PlayerMetaProgression, sub.player_id)
    if meta is None:
        return

    meta.shard_balance += stipend
    meta.total_shards_earned += stipend
    meta.updated_at = datetime.now(timezone.utc)
    session.add(meta)

    # Audit trail
    txn = ShardTransaction(
        player_id=sub.player_id,
        amount=stipend,
        balance_after=meta.shard_balance,
        source_type="subscription_stipend",
        source_id=sub.id,
        description=f"Ascendant monthly stipend ({stipend} shards)",
        created_at=datetime.now(timezone.utc),
    )
    session.add(txn)

    # Stipend log (idempotency + clawback tracking)
    log = SubscriptionStipendLog(
        subscription_id=sub.id,
        player_id=sub.player_id,
        shards_credited=stipend,
        period_key=period_key or datetime.now(timezone.utc).strftime("%Y-%m"),
        period_start=sub.current_period_start,
        stripe_invoice_id=invoice_id,
        created_at=datetime.now(timezone.utc),
    )
    session.add(log)


def _calculate_stipend_amount(sub: PlayerSubscription, session: Session) -> int:
    """Base 150 + streak-based bonus shards."""
    base = 150  # From game_configs in production
    streak_config = _get_streak_config(session)
    bonus = 0
    for milestone in streak_config:
        if sub.continuous_streak >= milestone["months"]:
            bonus = milestone.get("stipend_bonus", 0)
    return base + bonus

def _handle_subscription_checkout_completed(event: dict, session: Session) -> None:
    """New subscription created via Stripe Checkout."""
    session_obj = event["data"]["object"]
    metadata = session_obj.get("metadata", {})
    player_id = int(metadata.get("player_id", 0))
    plan_key = metadata.get("plan_key", "")

    stripe_sub_id = session_obj.get("subscription")
    if not stripe_sub_id:
        logger.error("subscription checkout.completed missing subscription ID")
        return

    # Fetch the subscription from Stripe to get period dates
    stripe_sub = stripe.Subscription.retrieve(stripe_sub_id)
    period_end = datetime.fromtimestamp(stripe_sub.current_period_end, tz=timezone.utc)
    price_id = stripe_sub["items"]["data"][0]["price"]["id"]

    activate_subscription(player_id, stripe_sub_id, plan_key, price_id,
                          period_end, session)
    session.commit()

    # NOTE: Stipend is NOT credited here. It will be credited when invoice.paid
    # fires (Stripe sends invoice.paid for the initial payment as well).
    logger.info("Subscription activated: player=%s plan=%s", player_id, plan_key)
```

```python
def _handle_invoice_paid(event: dict, session: Session) -> None:
    """Subscription renewal payment succeeded."""
    invoice = event["data"]["object"]
    sub_id = invoice.get("subscription")
    invoice_id = invoice.get("id")

    if not sub_id:
        return  # Not a subscription invoice

    sub = session.exec(
        select(PlayerSubscription).where(
            PlayerSubscription.stripe_subscription_id == sub_id
        )
    ).first()

    if not sub:
        # Out-of-order: invoice.paid arrived before checkout.session.completed.
        # Log and skip — checkout handler will create the subscription row,
        # and the next invoice.paid (or lazy stipend credit) will catch up.
        logger.warning("No PlayerSubscription for Stripe sub %s — likely out-of-order, skipping", sub_id)
        return

    # Get the new period end from Stripe
    stripe_sub = stripe.Subscription.retrieve(sub_id)
    new_period_end = datetime.fromtimestamp(
        stripe_sub.current_period_end, tz=timezone.utc
    )

    renew_subscription(sub, new_period_end, invoice_id, session)
    session.commit()

    logger.info("Subscription renewed: player=%s streak=%s cumulative=%s",
                sub.player_id, sub.continuous_streak, sub.cumulative_months)
```

## 8. Error Handling

### 8.1 Webhook Out-of-Order Resilience

| Scenario | Handling |
|:---|:---|
| `invoice.paid` arrives before `checkout.session.completed` | `invoice.paid` handler checks for existing `PlayerSubscription`. If missing, skips processing and logs a warning. The subsequent `checkout.session.completed` creates the row; the next `invoice.paid` or lazy stipend credit catches up. |
| Multiple `invoice.payment_failed` events | `start_grace_period()` is idempotent — only sets grace start if not already set. |
| `customer.subscription.deleted` after already `expired` | `expire_subscription()` checks status first — no-op if already expired. |
| `charge.refunded` for a subscription charge | Distinguished from purchase refunds by presence of `invoice` field on the charge object. |

### 8.2 Stripe API Errors

Same handling patterns as 3.1 (§4.1 in 3.1 design doc):
- `RateLimitError` → retry with backoff
- `InvalidRequestError` → log + return error
- `AuthenticationError` → log critical alert
- `APIConnectionError` → retry with backoff

### 8.3 Concurrent Access

- `resolve_subscription_status()` may be called from multiple endpoints simultaneously. Stipend crediting uses `subscription_stipend_log.period_key` as a unique constraint to prevent double-credits.
- `is_ascendant` flag on `players` is always written within a transaction alongside the subscription record update.
