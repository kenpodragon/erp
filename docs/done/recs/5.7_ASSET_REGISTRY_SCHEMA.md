## 2. New Table: `asset_registry`

Central registry for all visual assets. Every sprite, icon, background, portrait, badge, effect, and visual element in the game is a row in this table. The `render_definition` JSONB column contains all data needed to procedurally render the asset on the frontend — no filesystem images.

```sql
CREATE TABLE asset_registry (
    id                  SERIAL PRIMARY KEY,
    asset_key           VARCHAR(150) NOT NULL UNIQUE,
    category            VARCHAR(50) NOT NULL,
    display_name        VARCHAR(200),
    description         TEXT,
    render_definition   JSONB NOT NULL DEFAULT '{}',
    tags                JSONB NOT NULL DEFAULT '[]',
    source              VARCHAR(50) NOT NULL DEFAULT 'admin',
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- Primary lookup: asset_key is the main query path
CREATE INDEX idx_ar_asset_key ON asset_registry(asset_key);

-- Category filtering (admin grid view)
CREATE INDEX idx_ar_category ON asset_registry(category);

-- Source filtering (find generator vs manual entries)
CREATE INDEX idx_ar_source ON asset_registry(source);

-- Tag search (GIN index for JSONB array containment queries)
CREATE INDEX idx_ar_tags ON asset_registry USING GIN(tags);

-- Text search on display_name for admin search bar
CREATE INDEX idx_ar_display_name ON asset_registry(display_name);

-- Auto-update updated_at trigger
CREATE OR REPLACE FUNCTION trg_asset_registry_updated_at()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_asset_registry_updated_at
    BEFORE UPDATE ON asset_registry
    FOR EACH ROW
    EXECUTE FUNCTION trg_asset_registry_updated_at();
```

### Column Details

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | `SERIAL` | PK | Auto-incrementing surrogate key |
| `asset_key` | `VARCHAR(150)` | UNIQUE, NOT NULL | Canonical identifier. Format: `{prefix}_{name}` (e.g., `enemy_sludge`, `bg_ch1_far`, `avatar_pallid_mask`). This is what game tables reference via their `sprite_key` / `icon_sprite_key` columns. |
| `category` | `VARCHAR(50)` | NOT NULL | Asset type — determines which frontend renderer handles it. Values: `entity_sprite`, `class_sprite`, `background`, `item_icon`, `artifact_icon`, `achievement_icon`, `skill_icon`, `avatar`, `skin`, `badge`, `flair`, `spell_effect`, `ui_icon`, `narrative_image`, `portrait`. Validated at application level, not DB constraint, for forward-compatibility. |
| `display_name` | `VARCHAR(200)` | NULL | Human-readable name for admin display (e.g., "Sludge Stalker", "Chapter 1 Far Background"). |
| `description` | `TEXT` | NULL | Optional longer description or notes about the asset. |
| `render_definition` | `JSONB` | NOT NULL, DEFAULT `'{}'` | **Core payload.** Contains all data needed to procedurally render this asset. Structure varies by category (see Design doc §3 for per-category schemas). Includes shapes, colors, sizes, features, animations, gradients, composition layers, etc. |
| `tags` | `JSONB` | NOT NULL, DEFAULT `'[]'` | Freeform label array for filtering and search. Examples: `["book_1", "chapter_3", "void", "boss"]`, `["melee", "golem_family"]`. Queried with `@>` containment operator. |
| `source` | `VARCHAR(50)` | NOT NULL, DEFAULT `'admin'` | Origin tracking. Values: `seed` (migration), `admin` (manual), `generator` (C_ pipeline), `migrated` (converted from filesystem). |
| `created_at` | `TIMESTAMPTZ` | NOT NULL, DEFAULT `NOW()` | Row creation timestamp. |
| `updated_at` | `TIMESTAMPTZ` | NOT NULL, DEFAULT `NOW()` | Last modification timestamp. Auto-updated via trigger. |

### Design Decisions

**Why no FK from game tables?**
Existing `sprite_key` / `icon_sprite_key` columns across 10+ tables use loose string references. Adding FKs would require:
- ALTER on 10+ tables (high migration risk)
- Insertion order dependencies (can't seed entity before its sprite)
- Breaking existing code that sets keys before assets exist

Instead, orphan detection endpoints (`/orphans/missing`, `/orphans/unused`) provide the same integrity guarantees without schema coupling.

**Why no category CHECK constraint?**
New categories will be added as the game evolves (e.g., `map_marker`, `weather_effect`). Application-level validation with a configurable list is more flexible than a DB constraint requiring migration for each new category.

**Why JSONB for tags instead of a junction table?**
Tags are freeform labels, not a managed taxonomy. JSONB array with GIN index provides:
- Simple queries: `WHERE tags @> '["book_1"]'`
- No junction table overhead
- Flexible: admins create tags without pre-registration

## 3. ALTER TABLE: `shop_items` and `shop_bundles`

Rename `icon_path` (which stored filesystem paths) to `icon_asset_key` (which stores registry keys).

```sql
-- Rename columns
ALTER TABLE shop_items RENAME COLUMN icon_path TO icon_asset_key;
ALTER TABLE shop_bundles RENAME COLUMN icon_path TO icon_asset_key;

-- Migrate existing data from file paths to asset_keys
-- (Only needed if existing rows have non-NULL icon_path values)
UPDATE shop_items
SET icon_asset_key = CASE
    WHEN category = 'skin' THEN 'skin_' || LOWER(REPLACE(item_key, ' ', '_'))
    WHEN category = 'flair' THEN 'flair_' || LOWER(REPLACE(item_key, ' ', '_'))
    WHEN category = 'badge' THEN 'badge_' || LOWER(REPLACE(item_key, ' ', '_'))
    WHEN category = 'avatar' THEN 'avatar_' || LOWER(REPLACE(item_key, ' ', '_'))
    WHEN category = 'booster' THEN 'ui_booster_' || LOWER(REPLACE(item_key, ' ', '_'))
    ELSE icon_asset_key
END
WHERE icon_asset_key IS NOT NULL;
```

## 5. Orphan Detection Query Patterns

### 5.1 Missing Assets (referenced but not registered)

```sql
-- Collect all distinct sprite_key values from game tables, LEFT JOIN to registry
WITH all_references AS (
    SELECT DISTINCT sprite_key AS asset_key, 'entity_gameplay_data' AS source_table, 'sprite_key' AS source_column, 'entity_sprite' AS suggested_category
    FROM entity_gameplay_data WHERE sprite_key IS NOT NULL
    UNION ALL
    SELECT DISTINCT sprite_key, 'character_classes', 'sprite_key', 'class_sprite'
    FROM character_classes WHERE sprite_key IS NOT NULL
    UNION ALL
    SELECT DISTINCT background_sprite_key, 'scene_gameplay_data', 'background_sprite_key', 'background'
    FROM scene_gameplay_data WHERE background_sprite_key IS NOT NULL
    UNION ALL
    SELECT DISTINCT sprite_key, 'inventory_items', 'sprite_key', 'item_icon'
    FROM inventory_items WHERE sprite_key IS NOT NULL
    UNION ALL
    SELECT DISTINCT icon_sprite_key, 'curated_artifacts', 'icon_sprite_key', 'artifact_icon'
    FROM curated_artifacts WHERE icon_sprite_key IS NOT NULL
    UNION ALL
    SELECT DISTINCT icon_sprite_key, 'player_artifacts', 'icon_sprite_key', 'artifact_icon'
    FROM player_artifacts WHERE icon_sprite_key IS NOT NULL
    UNION ALL
    SELECT DISTINCT icon_sprite_key, 'achievements', 'icon_sprite_key', 'achievement_icon'
    FROM achievements WHERE icon_sprite_key IS NOT NULL
    UNION ALL
    SELECT DISTINCT icon_asset_key, 'shop_items', 'icon_asset_key', 'ui_icon'
    FROM shop_items WHERE icon_asset_key IS NOT NULL
    UNION ALL
    SELECT DISTINCT avatar_preset_key, 'players', 'avatar_preset_key', 'avatar'
    FROM players WHERE avatar_preset_key IS NOT NULL
)
SELECT r.asset_key, r.suggested_category,
       json_agg(json_build_object('table', r.source_table, 'column', r.source_column)) AS referenced_in
FROM all_references r
LEFT JOIN asset_registry ar ON ar.asset_key = r.asset_key
WHERE ar.id IS NULL
GROUP BY r.asset_key, r.suggested_category;
```

### 5.2 Unused Assets (registered but not referenced)

```sql
-- Find registry entries whose asset_key appears in NO game table
SELECT ar.asset_key, ar.category, ar.source, ar.created_at
FROM asset_registry ar
WHERE NOT EXISTS (SELECT 1 FROM entity_gameplay_data WHERE sprite_key = ar.asset_key)
  AND NOT EXISTS (SELECT 1 FROM character_classes WHERE sprite_key = ar.asset_key)
  AND NOT EXISTS (SELECT 1 FROM scene_gameplay_data WHERE background_sprite_key = ar.asset_key)
  AND NOT EXISTS (SELECT 1 FROM inventory_items WHERE sprite_key = ar.asset_key)
  AND NOT EXISTS (SELECT 1 FROM curated_artifacts WHERE icon_sprite_key = ar.asset_key)
  AND NOT EXISTS (SELECT 1 FROM player_artifacts WHERE icon_sprite_key = ar.asset_key)
  AND NOT EXISTS (SELECT 1 FROM achievements WHERE icon_sprite_key = ar.asset_key)
  AND NOT EXISTS (SELECT 1 FROM shop_items WHERE icon_asset_key = ar.asset_key)
  AND NOT EXISTS (SELECT 1 FROM shop_bundles WHERE icon_asset_key = ar.asset_key)
  AND NOT EXISTS (SELECT 1 FROM players WHERE avatar_preset_key = ar.asset_key)
ORDER BY ar.category, ar.asset_key;
```
