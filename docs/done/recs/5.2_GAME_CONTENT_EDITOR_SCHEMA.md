# SCHEMA 5.2: Game Content Editor (Narrative & World Data)

Database schema additions for the Game Content Editor. This phase adds **2 new tables**, **1 new column** on an existing table, and **1 new column + migration** on another existing table. All other editing operates on existing models.

**Requirements:** [5.2_GAME_CONTENT_EDITOR.md](5.2_GAME_CONTENT_EDITOR.md) | **Design:** [5.2_GAME_CONTENT_EDITOR_DESIGN.md](5.2_GAME_CONTENT_EDITOR_DESIGN.md)
**Parent:** [5.0_ADMIN_SYSTEMS.md](5.0_ADMIN_SYSTEMS.md) §2

## 1. New Table: `backgrounds`

Stores background definitions for scene rendering. Replaces the loose `background_sprite_key` string on `scene_gameplay_data` with a structured record.

```sql
-- Migration: 057_backgrounds_and_wave_configs.sql

CREATE TABLE backgrounds (
    id              SERIAL PRIMARY KEY,
    name            VARCHAR(100) NOT NULL UNIQUE,
    description     TEXT,
    background_key  VARCHAR(100) NOT NULL UNIQUE,
    parallax_config JSONB DEFAULT '{}'::jsonb,
    time_of_day     VARCHAR(50),
    mood            VARCHAR(50),
    color_palette   JSONB,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- Auto-update trigger
CREATE TRIGGER update_backgrounds_modtime
    BEFORE UPDATE ON backgrounds
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();
```

### 1.1 Column Reference

| Column | Type | Nullable | Default | FK | Description |
|:---|:---|:---|:---|:---|:---|
| `id` | serial | NO | auto | — | Primary key |
| `name` | varchar(100) | NO | — | — | Display name (e.g., "Dark Corridor") |
| `description` | text | YES | NULL | — | Admin reference description |
| `background_key` | varchar(100) | NO | — | — | Asset reference key (links to Asset Registry `background` category) |
| `parallax_config` | jsonb | YES | {} | — | Parallax layer config: `{"layers": [{"depth": 0.2, "speed": 0.5}]}` |
| `time_of_day` | varchar(50) | YES | NULL | — | Time variant (day, night, dusk, dawn) |

| `updated_at` | timestamptz | NO | NOW() | — | Updated timestamp |

**Indexes:** `name` (unique), `background_key` (unique) — both via UNIQUE constraints.

## 2. New Table: `scene_wave_configs`

Per-scene wave composition configuration. Defines how enemy waves are composed for each scene.

```sql
CREATE TABLE scene_wave_configs (
    id                  SERIAL PRIMARY KEY,
    scene_id            INTEGER NOT NULL UNIQUE REFERENCES scenes(id) ON DELETE CASCADE,
    max_enemies_per_wave INTEGER NOT NULL DEFAULT 5,
    wave_count          INTEGER NOT NULL DEFAULT 10,
    spawn_interval_ms   INTEGER NOT NULL DEFAULT 2000,
    scaling_factor      DOUBLE PRECISION NOT NULL DEFAULT 1.0,
    hp_multiplier       DOUBLE PRECISION NOT NULL DEFAULT 1.0,
    gold_multiplier     DOUBLE PRECISION NOT NULL DEFAULT 1.0,
    entity_pool         JSONB NOT NULL DEFAULT '[]'::jsonb,
    boss_entity_id      INTEGER REFERENCES entities(id) ON DELETE SET NULL,
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- Indexes
CREATE INDEX idx_scene_wave_configs_scene ON scene_wave_configs(scene_id);

-- Auto-update trigger
CREATE TRIGGER update_scene_wave_configs_modtime
    BEFORE UPDATE ON scene_wave_configs
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();
```

### 2.1 Column Reference

| Column | Type | Nullable | Default | FK | Description |
|:---|:---|:---|:---|:---|:---|
| `id` | serial | NO | auto | — | Primary key |
| `scene_id` | integer | NO | — | scenes(id) CASCADE | One config per scene (unique) |
| `max_enemies_per_wave` | integer | NO | 5 | — | Maximum simultaneous enemies |
| `wave_count` | integer | NO | 10 | — | Number of waves in this scene |
| `spawn_interval_ms` | integer | NO | 2000 | — | Base spawn interval in milliseconds |
| `scaling_factor` | double precision | NO | 1.0 | — | Difficulty scaling multiplier |
| `hp_multiplier` | double precision | NO | 1.0 | — | HP scaling multiplier for all entities in this scene |
| `gold_multiplier` | double precision | NO | 1.0 | — | Gold reward multiplier |
| `entity_pool` | jsonb | NO | [] | — | Array of `{entity_id, weight, min_wave, max_wave}` |
| `boss_entity_id` | integer | YES | NULL | entities(id) SET NULL | Boss entity for boss waves |
| `created_at` | timestamptz | NO | NOW() | — | Created timestamp |
| `updated_at` | timestamptz | NO | NOW() | — | Updated timestamp |

### 2.2 Entity Pool JSONB Structure

Each entry in the `entity_pool` array:
```json
{
  "entity_id": 42,
  "weight": 1.0,
  "min_wave": 1,
  "max_wave": null
}
```

- `entity_id` (integer, required): References `entities.id`
- `weight` (float, required): Relative spawn probability (normalized across pool)
- `min_wave` (integer, required): Earliest wave this entity can appear (1-based)
- `max_wave` (integer, nullable): Latest wave (null = no limit)

**Indexes:** `scene_id` (unique via constraint + additional index for query performance).

## 3. Altered Table: `scene_gameplay_data` — Add `background_id`

```sql
-- Add background_id FK column
ALTER TABLE scene_gameplay_data
    ADD COLUMN background_id INTEGER REFERENCES backgrounds(id) ON DELETE SET NULL;

-- Migrate existing background_sprite_key values to backgrounds table
-- Step 1: Create background records from distinct existing keys
INSERT INTO backgrounds (name, background_key)
    SELECT DISTINCT
        background_sprite_key,
        background_sprite_key
    FROM scene_gameplay_data
    WHERE background_sprite_key IS NOT NULL
        AND background_sprite_key != ''
ON CONFLICT (background_key) DO NOTHING;

-- Step 2: Populate background_id from matching backgrounds
UPDATE scene_gameplay_data sgd
    SET background_id = b.id
    FROM backgrounds b
    WHERE sgd.background_sprite_key = b.background_key
        AND sgd.background_sprite_key IS NOT NULL
        AND sgd.background_sprite_key != '';

-- Index for FK lookups
CREATE INDEX idx_scene_gameplay_data_background ON scene_gameplay_data(background_id);

-- Note: background_sprite_key is retained for backwards compatibility.
-- New code should use background_id. background_sprite_key can be dropped in a future migration.
```

### 3.1 Column Changes

| Column | Action | Type | FK | Notes |
|:---|:---|:---|:---|:---|
| `background_id` | ADD | integer, nullable | backgrounds(id) SET NULL | New FK replacing background_sprite_key |
| `background_sprite_key` | RETAIN (deprecated) | varchar(100) | — | Kept for backwards compatibility; new code uses `background_id` |

## 6. SQLModel Definitions

### 6.1 New Model: `Background`

```python
# In backend/models/content.py (new file)

from datetime import datetime
from typing import Optional, Any
from sqlmodel import SQLModel, Field
from sqlalchemy import Column
from sqlalchemy.types import JSON


class Background(SQLModel, table=True):
    """Structured background definitions for scene rendering."""
    __tablename__ = "backgrounds"

    id: Optional[int] = Field(default=None, primary_key=True)
    name: str = Field(max_length=100, nullable=False, unique=True)
    description: Optional[str] = Field(default=None)
    background_key: str = Field(max_length=100, nullable=False, unique=True)
    parallax_config: Optional[Any] = Field(default=None, sa_column=Column(JSON))
    time_of_day: Optional[str] = Field(default=None, max_length=50)
    mood: Optional[str] = Field(default=None, max_length=50)
    color_palette: Optional[Any] = Field(default=None, sa_column=Column(JSON))
    created_at: Optional[datetime] = Field(default=None)
    updated_at: Optional[datetime] = Field(default=None)


class SceneWaveConfig(SQLModel, table=True):
    """Per-scene wave composition configuration."""
    __tablename__ = "scene_wave_configs"

    id: Optional[int] = Field(default=None, primary_key=True)
    scene_id: int = Field(foreign_key="scenes.id", nullable=False, unique=True)
    max_enemies_per_wave: int = Field(default=5, nullable=False)
    wave_count: int = Field(default=10, nullable=False)
    spawn_interval_ms: int = Field(default=2000, nullable=False)
    scaling_factor: float = Field(default=1.0, nullable=False)
    hp_multiplier: float = Field(default=1.0, nullable=False)
    gold_multiplier: float = Field(default=1.0, nullable=False)
    entity_pool: Any = Field(default=[], sa_column=Column(JSON, nullable=False, server_default="'[]'::jsonb"))
    boss_entity_id: Optional[int] = Field(default=None, foreign_key="entities.id")
    created_at: Optional[datetime] = Field(default=None)
    updated_at: Optional[datetime] = Field(default=None)
```
