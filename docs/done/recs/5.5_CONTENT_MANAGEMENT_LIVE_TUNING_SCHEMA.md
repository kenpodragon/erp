# SCHEMA 5.5: Content Management & Live Tuning

Database schema impact analysis for the Content Management & Live Tuning system. This phase adds **no new tables**, **no new columns**, and **no new migrations**. All specialized tuning panels read from and write to the existing `game_configs` table via existing CRUD endpoints.

**Requirements:** [5.5_CONTENT_MANAGEMENT_LIVE_TUNING.md](5.5_CONTENT_MANAGEMENT_LIVE_TUNING.md) | **Design:** [5.5_CONTENT_MANAGEMENT_LIVE_TUNING_DESIGN.md](5.5_CONTENT_MANAGEMENT_LIVE_TUNING_DESIGN.md)
**Parent:** [5.0_ADMIN_SYSTEMS.md](5.0_ADMIN_SYSTEMS.md) §2

---

## 1. No Migration Required

5.5 is a **frontend-only enhancement** to the existing GameConfigs admin page. All data already exists in the `game_configs` table (137 keys across 18 categories). The specialized panels (Drop Rate Manager, Skill Balance Viewer, Economy Tuning) are presentation layers over the same data.

## 2. Existing Table: `game_configs` (Unchanged)

Verified against live database (2026-03-15):

```sql
-- No changes — table structure remains:
CREATE TABLE game_configs (
    key         VARCHAR(100) PRIMARY KEY,
    value_json  JSONB        NOT NULL,
    description TEXT,
    updated_at  TIMESTAMPTZ  DEFAULT NOW(),
    category    VARCHAR(50),
    game_impact TEXT,
    updated_by  INTEGER      REFERENCES players(id) ON DELETE SET NULL
);
```

### 2.1 Column Reference (Existing — No Changes)

| Column | Type | Nullable | Default | FK | Description |
|:---|:---|:---|:---|:---|:---|
| `key` | varchar(100) | NO | — | — | Primary key. Config key name. |
| `value_json` | jsonb | NO | — | — | Config value (any JSON type). |
| `description` | text | YES | NULL | — | Human-readable description of the key. |
| `updated_at` | timestamptz | YES | NOW() | — | Last update timestamp. |
| `category` | varchar(50) | YES | NULL | — | Grouping category for UI organization. |
| `game_impact` | text | YES | NULL | — | Description of gameplay impact. |
| `updated_by` | integer | YES | NULL | players(id) SET NULL | Admin who last updated. |

## 4. Data Dictionary Updates

No new entries needed — no schema changes. Existing `game_configs` and `skills` entries remain accurate.

### 4.1 Documentation Note

Add to `db/data_dictionary.md` under the `game_configs` section:

> **Admin UI organization:** The GameConfigs admin page groups keys by the `category` column into tabbed views. Three specialized tabs provide purpose-built interfaces: Drop Rates (artifact/item drop tuning), Skill Balance (read-only cross-reference with computed DPS), and Economy (essence XP curve, salvage rates, subscription boosts). All specialized tabs read and write to the same `game_configs` table — no parallel data stores.
