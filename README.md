# ERP: Elysium Rising mmorPg

**ERP** is a unique MMORPG experience set in the **Elysium Rising** universe, based on the *Towers of Elysium* book trilogy. 

## Project Overview
The game draws its lore, characters, and enemies directly from the *Towers of Elysium* series. Players progress through incremental clicker levels that mirror the chapters of the books, accompanied by Eleven Reader audio narration.
